# Физика

Проект с материалами по физике для 7-9 классов.

## Структура проекта

-lessons
|-{class} - номер класса
    |-{class}_{number_lesson}_{prefix}_Тема урока (prefix - один из следующих ЛР(Лабораторная работа), КР(Контрольная работа), УИ(Урок-иследование), РЗ(Решение задач))
        |-images - папка с картинками и рисунками по теме
        |-{class}_{number_lesson}_{prefix}_Тема урока.pptx - презентация по теме
        |-{class}_{number_lesson}_{prefix}_Тема урока.md - план урока, основа для презентации
        |-task.md - задачи по теме
