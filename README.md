# Физика

Учебные материалы по физике для 7–9 классов: конспекты и планы уроков, презентации PowerPoint, задачи, лабораторные и контрольные работы.

## Структура проекта

```text
physics/
├── lessons/                      # материалы уроков
│   ├── 7/                        # 7 класс — 68 уроков
│   ├── 8/                        # 8 класс — 68 уроков
│   └── 9/                        # 9 класс — 102 урока
├── templates/
│   └── class_number_theme/       # шаблоны для нового урока
│       ├── lesson.md             # структура плана урока
│       └── task.md               # шаблон задачи
├── tools/
│   └── make_pptx.py              # генератор презентаций
├── .opencode/
│   └── skills/physics-teacher/   # навык учителя физики для OpenCode
│       └── SKILL.md
├── agent.md                      # описание проекта для агентов
├── LICENSE                       # лицензия MIT
└── README.md
```

## Формат урока

Материалы одного урока лежат в отдельной папке:

```text
lessons/{класс}/{класс}_{номер}_{тип}_{тема}/
```

Например:

```text
lessons/8/8_45_Закон_Ома_для_участка_цепи/
```

Внутри папки могут находиться:

- `*.md` — конспект или план урока (основа для проведения занятия);
- `*_presentation.md` — структура и текст слайдов;
- `*.pptx` — готовая презентация к уроку;
- `task.md` — задачи по теме: не менее 10 задач трёх уровней сложности (базовый, средний, повышенный), с ответами и решениями;
- `README.md` — описание материалов урока;
- `План_урока.md`, `Порядок_выполнения_работы.md`, `Справочник_ученика.md` — дополнительные материалы к лабораторным работам;
- `images/` — иллюстрации и схемы (если есть).

### Типы уроков

Тип урока указывается в имени папки:

| Префикс | Значение |
|---------|----------|
| `ЛР` | лабораторная работа |
| `КР` | контрольная работа |
| `УИ` | урок-исследование |
| `РЗ` | решение задач |
| `Конференция` | урок-конференция |
| `Подготовка` | подготовка к контрольной работе |
| `Повторение` | итоговое повторение |
| `Резерв` / `Резервный` | резервный урок |
| `Практикум` | практикум |

Если тип не указан, это обычный урок изучения нового материала.

## Инструменты

### Навык physics-teacher

Файл [`.opencode/skills/physics-teacher/SKILL.md`](.opencode/skills/physics-teacher/SKILL.md) содержит инструкции для учителя физики: подготовка уроков, объяснение тем, создание презентаций и заданий.

### Генератор презентаций

`tools/make_pptx.py` создаёт презентации PowerPoint на основе списка слайдов. Требуется Python 3 и библиотека `python-pptx`:

```bash
pip install python-pptx
```

Пример использования:

```python
from tools.make_pptx import make_pptx

slides = [
    ("title", "Закон Ома для участка цепи", "Урок 45 • Физика, 8 класс"),
    ("bullets", "Цели урока", [
        "Исследовать зависимость силы тока от напряжения",
        "Сформулировать закон Ома",
        "Научиться решать задачи",
    ]),
    ("formula", "Закон Ома", "I = U / R", "Сила тока прямо пропорциональна напряжению и обратно пропорциональна сопротивлению"),
    ("task", "Задача 1", "U = 12 В, R = 6 Ом. Найдите силу тока."),
    ("solution", "Задача 1 — решение", ["I = U / R", "I = 12 / 6 = 2 А"], "Ответ: 2 А"),
    ("end", "Домашнее задание", ["§ 45, вопросы 1–5", "Упражнение 30"]),
]

make_pptx("lessons/8/8_45_Закон_Ома_для_участка_цепи/презентация.pptx", slides, footer="8 класс")
```

Поддерживаемые типы слайдов: `title`, `section`, `bullets`, `two_col`, `formula`, `task`, `solution`, `end`.

## Как добавить новый урок

1. Создайте папку по шаблону `lessons/{класс}/{класс}_{номер}_{тип}_{тема}/`.
2. Скопируйте в неё шаблоны `templates/class_number_theme/lesson.md` и `task.md`.
3. Заполните конспект урока, опишите структуру слайдов и подготовьте задачи. Для уроков типа «Решение задач» подготовьте не менее 10 задач трёх уровней сложности в `task.md`.
4. Сгенерируйте презентацию через `tools/make_pptx.py` и сохраните её в папку урока.
5. При необходимости добавьте `README.md` с описанием материалов урока и папку `images/` для иллюстраций.

## Соглашения

- Все материалы создаются на русском языке.
- Имена папок: `{класс}_{номер}_{тип}_{тема}`, слова разделяются подчёркиваниями.
- Каждая задача в презентации занимает два слайда: сначала условие, затем решение и ответ.
- В уроках типа «Решение задач» (`РЗ` и аналогичные) — не менее 10 задач, распределённых по трём уровням сложности: базовый, средний, повышенный. В `task.md` используется сквозная нумерация задач.
- В лабораторных, контрольных работах и заданиях на решение задач не используются исторические справки — только задания, ход работы, решения и ответы.
- Сложность материала адаптируется к возрасту и уровню подготовки учащихся.
