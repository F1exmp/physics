# Физика

Проект с материалами по физике для 7-9 классов.

## Структура проекта

```
physics/
├── lessons/              # Уроки по классам
│   ├── 7/               # 7 класс - 69 уроков
│   │   ├── 01_Физика_наука_о_природе/
│   │   │   └── tasks.md # Задачи к уроку (пустой)
│   │   ├── 02_Виды_физических_явлений/
│   │   │   └── tasks.md
│   │   └── ...
│   ├── 8/               # 8 класс
│   └── 9/               # 9 класс
├── ptp/                 # ПТП (Программа тематического планирования)
│   ├── 7 класс физика ПТП.xls
│   ├── 8 класс физика ПТП.xls
│   ├── 9 класс физика ПТП.xls
│   ├── 9 класс физика Абаринова ПТП.xls
│   └── 9 класс физика Виноградова ПТП.xls
└── .opencode/           # Конфигурация опенсервера
    ├── agents/
    │   ├── physics.md   # Локальный агент учителя физики
    │   └── fizik334.md  # Глобальный агент учителя физики
    ├── skills/
    │   └── physics-teacher/
    │       └── SKILL.md # Скилл учителя физики
    └── opencode.json    # Конфигурация проекта
```

## 7 класс

Всего уроков: 69

### Темы уроков:
- Физика — наука о природе
- Виды физических явлений
- Измерение физических величин
- Строение вещества
- Агрегатные состояния вещества
- Механическое движение
- Силы и взаимодействие тел
- Работа, мощность, энергия

### Структура урока:
- Папка урока: `{number}_{тема}/`
- Файл задач: `tasks.md` (пустой, готов к наполнению)

## Инструменты

### Агенты:
- **fizik334** — учитель физики для 7-9 классов (подготовка уроков, объяснение концепций, создание материалов)

### Скилл:
- **physics-teacher** — инструкция для учителя физики (подготовка уроков, объяснение тем, создание заданий)

## Как использовать

1. Для создания материалов по урокам используйте_AGENT fizik334
2. Для наполнения задач откройте соответствующий файл tasks.md
3. Новые темы добавляются через анализ файлов ПТП в папке ptp/
