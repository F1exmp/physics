# Описание агента проекта Physics

## Обзор проекта
Образовательный проект для преподавания физики в 7, 8 и 9 классах. Содержит учебные материалы, презентации и планы уроков.

## Структура проекта
```
physics/
├── 7/           - Презентации по физике для 7 класса
├── 8/           - Презентации по физике для 8 класса
├── 9/           - Презентации по физике для 9 класса
├── books/       - Учебные книги и материалы
├── Программы/   - Программы обучения
└── *.xls        - Поурочно-тематические планы для каждого класса
```

## Типы контента
- **Презентации (.pptx)**: Учебные материалы, организованные по классам и темам
- **Файлы Excel (*.xls)**: Например: "7 класс физика ПТП.xls" - планы уроков и расписание
- **Учебные материалы**: Книги и учебные программы

## Темы по классам

### 7 класс
- Введение в физику как науку
- Физические величины и измерения
- Строение вещества
- Механическое движение
- Инерция и законы Ньютона

### 8 класс
- Молекулярно-кинетическая теория
- Агрегатные состояния вещества
- Поверхностное натяжение и капиллярность
- Внутренняя энергия
- Теплопередача
- Тепловые уравнения

### 9 класс
- Материальная точка и движение
- Равномерное и равноускоренное движение
- Свободное падение
- Движение по окружности
- Законы Ньютона
- Силы (упругость, трение, закон Гука)

## Рекомендации для агентов
1. **Создание контента**: Создавать учебные материалы по физике для 7-9 классов на русском языке
2. **Организация файлов**: Следовать существующей схеме именования (КЛАСС_ТЕМА_НОМЕР_Описание.pptx)
3. **Ссылки на темы**: При ссылке на темы использовать формат: "7_05" или "8_03"
4. **Язык**: Весь контент должен быть на русском языке
