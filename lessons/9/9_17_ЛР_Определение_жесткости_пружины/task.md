# Задания к ЛР «Определение жёсткости пружины»

## Подготовительные вопросы

1. Запишите закон Гука.
2. По какой формуле вычисляют жёсткость из опыта?

## Обработка результатов

1. Заполните таблицу: m, F = mg, Δl.
2. Вычислите k для каждого груза.
3. Постройте график F(Δl): прямая через ноль?
4. Найдите среднее k.

## Контрольные вопросы

**Вопрос 1.** Почему график должен быть прямой через начало координат?

**Вопрос 2.** Что произойдёт при перегрузке пружины?

---

## Ответы

**Ответ 1:** F = k·Δl.
**Ответ 2:** k = F/Δl = mg/Δl.
**Ответ 1:** без груза деформации нет: F = 0 и Δl = 0; зависимость линейна.
**Ответ 2:** деформация станет пластической — пружина не вернётся, закон Гука нарушится.
