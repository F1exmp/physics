## Ключевые формулы

```
Импульс тела:      p = m · v
Закон сохранения:  m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′
Неупругое:         m₁v₁ + m₂v₂ = (m₁ + m₂)·v′
Упругое (m1=m2):   обмен скоростями
```
