## Ключевые формулы

```
Сила тяжести:  A = +mgh (вниз) / A = −mgh (вверх) / A = 0 (горизонталь)
Сила упругости: A = kx² / 2            (сила переменная!)
Сила трения:   A = −μ·N·s = −μ·m·g·s   (горизонталь: N = mg)
```
