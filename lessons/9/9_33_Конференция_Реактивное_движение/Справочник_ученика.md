# Справочник ученика. Реактивное движение

## Определение
**Реактивное движение** — движение тела, которое возникает при отделении от него с некоторой скоростью какой-то части его массы (или вещества из среды).

Тело движется **в одну сторону**, потому что отбрасывает вещество **в противоположную**. Опора (земля, вода, воздух) для такого движения не нужна — поэтому ракета летит в пустоте.

## Связь с законом сохранения импульса
Если тело покоится, суммарный импульс системы равен нулю. При выбросе массы внутренние силы не могут изменить суммарный импульс, поэтому:

$$0 = M\cdot v - m\cdot u \quad\Rightarrow\quad \boxed{M\,v = m\,u}$$

- **M** — масса тела после выброса (ракета без газа, кальмар без воды), кг;
- **v** — скорость тела после выброса, м/с;
- **m** — масса выброшенного вещества (газа, воды), кг;
- **u** — скорость выброшенного вещества, м/с.

Отсюда скорость тела: **v = m·u / M**.
Вывод: чем больше масса и скорость отброшенного вещества (его импульс m·u), тем быстрее полетит тело. Направления противоположны.

Важно: отбросив части последовательно (ступени, порции газа), можно разгоняться дальше — каждый выброс снова даёт прирост скорости, а сброс ступени уменьшает M, делая разгон эффективнее.

## Примеры
- **Природа:** кальмар (вода из воронки, рывки до 10–15 м/с), медуза (сокращение купола), «стреляющие» семена и грибы (выброс спор).
- **Транспорт:** ракета (газы из сопла, 2–3 км/с), гидроцикл и водомётный катер (вода из сопла насоса), реактивный самолёт (газы из турбины).
- **Быт:** воздушный шарик, поливалка-вертушка (спринклер), отдача оружия и шланга.

## Алгоритм решения задач на отдачу
1. Записать массы: масса тела до (M₀), масса выбрасываемого вещества (m). Масса тела после: M = M₀ − m.
2. Убедиться, что начальный импульс равен нулю (тело покоилось).
3. Написать закон сохранения импульса вдоль одной прямой: 0 = M·v − m·u.
4. Выразить v = m·u / M, подставить числа, посчитать.
5. Указать направление: тело летит в сторону, противоположную выбросу вещества.

## Таблица «пример — рабочее тело — куда летим»

| Пример | Рабочее тело (что отбрасываем) | Куда летит тело |
|---|---|---|
| Ракета | раскалённые газы (2–3 км/с) | вперёд (газы назад) |
| Кальмар | вода из мантии через воронку | назад (вода вперёд через сифон) |
| Медуза | вода из-под купола | вперёд куполом |
| Гидроцикл / водомётный катер | вода из сопла насоса | вперёд (струя назад) |
| Реактивный самолёт | выхлопные газы турбины | вперёд (газы назад) |
| Воздушный шарик | воздух из горловины | назад (воздух вперёд) |
| Поливалка-вертушка | струи воды из сопел | вращение против струй |
| Отдача оружия | пуля/снаряд | назад (пуля вперёд) |
