# Подготовка к КР «ЭМ поле. Квантовые явления»

## Формулы для повторения

- c = 3·10⁸ м/с; λν = c
- α = β (углы от перпендикуляра)
- n₁ sin α = n₂ sin β; n = c/v
- D = 1/F
- E = hν; спектры
- α: A−4, Z−2; β: Z+1
- N = N₀(1/2)^(t/T); E = mc²
