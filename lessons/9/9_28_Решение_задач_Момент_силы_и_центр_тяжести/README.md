## 🔑 Ключевые формулы и понятия

### Момент силы:
```
M = F × d
где:
M — момент силы [Н·м]
F — сила [Н]
d — плечо силы [м]
```

### Плечо силы:
Кратчайшее расстояние от оси вращения до линии действия силы.

### Условия равновесия твёрдого тела:
1. **Первое условие:** ∑F = 0 (сумма всех сил равна нулю)
2. **Второе условие:** ∑M = 0 (сумма всех моментов равна нулю)

### Условие равновесия рычага:
```
F₁ × l₁ = F₂ × l₂
```

### Центр тяжести системы точек:
Центр тяжести делит отрезок обратно пропорционально массам.
