# Порядок выполнения лабораторной работы

## «Определение работы силы трения при равномерном движении тела по горизонтальной поверхности»

**Класс 9. Урок №36.**

---

## Цель работы

Научиться опытным путём определять силу трения скольжения (по показаниям динамометра при равномерном движении) и вычислять работу силы трения по формуле **A = Fтр · s**; проверить, что работа силы трения пропорциональна весу тела и пройденному пути.

## Оборудование

- Динамометр лабораторный (предел 5 Н, цена деления 0,1 Н);
- Деревянный брусок;
- Набор грузов по 100 г;
- Линейка или измерительная лента (цена деления 1 мм);
- Деревянная поверхность (доска / крышка стола).

## Техника безопасности

1. Нагружайте динамометр только в пределах шкалы (не более 5 Н).
2. Не роняйте грузы и брусок; грузы кладите на брусок над столом, придерживая рукой.
3. Не тяните брусок к краю стола — следите, чтобы он не падал.
4. Не размахивайте приборами; соблюдайте порядок на рабочем месте.
5. После окончания работы приведите рабочее место в порядок и сдайте его учителю.

3. Подготовьте деревянную поверхность: протрите её от пыли, отметьте стартовую линию.
4. **Опыт 1.** Прикрепите динамометр к бруску. Тяните брусок **равномерно** (без рывков, постоянные показания динамометра!) вдоль линейки на расстояние s₁ = 50 см. Зафиксируйте показание динамометра F — это и есть Fтр. Повторите измерение 3 раза, возьмите среднее.
5. Запишите в таблицу: вес (брусок, без грузов), путь s₁, силу трения Fтр₁. Переведите путь в метры: s = 0,50 м.

## Обработка результатов

**1. Средние значения:**
- Fтр(ср) = (0,2 + 0,6 + 1,0) / 3 = 0,6 Н;
- A(ср) = (0,10 + 0,24 + 0,30) / 3 = 0,64 / 3 ≈ 0,21 Дж.

**2. Сравнение с теорией:** измеренные силы трения совпали с расчётными Fтр = μ·N при μ = 0,2 — метод «показания динамометра = сила трения» подтверждается.

**3. Погрешность (для опыта 1):**
- абсолютные: ΔFтр = 0,05 Н; Δs = 0,005 м;
- относительная: εA = ΔFтр/Fтр + Δs/s = 0,05/0,2 + 0,005/0,50 = 0,25 + 0,01 = 0,26, то есть εA ≈ 26 %;
- абсолютная погрешность работы: ΔA = εA · A = 0,26 · 0,10 = 0,026 ≈ 0,03 Дж;
- результат: **A₁ = (0,10 ± 0,03) Дж**.

*Большая относительная погрешность объясняется малым значением силы трения в первом опыте — это нормально для учебных измерений.*

**4. Вывод (образец):**
«Мы определили силу трения скольжения по показаниям динамометра при равномерном движении бруска по деревянной поверхности и вычислили работу силы трения A = Fтр·s. Опыты показали: чем больше вес бруска с грузом, тем больше сила трения, а работа силы трения пропорциональна и силе трения, и пройденному пути. Измеренные значения совпали с расчётными по формуле Fтр = μN (μ ≈ 0,2) в пределах погрешности измерений. Работа силы трения отрицательна с точки зрения энергетики: энергия переходит во внутреннюю».

## Контрольные вопросы (с ответами)

**1. Почему при равномерном движении показания динамометра равны силе трения?**
*Ответ:* При равномерном прямолинейном движении равнодействующая всех сил равна нулю. По горизонтали на брусок действуют только сила тяги (упругость пружины) и сила трения, значит Fтяги = Fтр по модулю, а пружина как раз показывает силу тяги.

**2. Как изменится сила трения, если на брусок положить ещё один груз? Почему?**
*Ответ:* Увеличится: сила трения Fтр = μN, а реакция опоры N равна весу бруска с грузом. Добавление груза увеличивает вес и N, поэтому Fтр возрастает во столько же раз (μ и поверхность не меняются).

**3. Чему равна работа силы трения по знаку и почему?**
*Ответ:* Отрицательна: A = Fтр·s·cos180° = −Fтр·s. Сила трения направлена против перемещения, она не сообщает телу энергию, а «отбирает» её — механическая энергия переходит во внутреннюю (нагрев).

**4. Зависит ли сила трения от площади соприкосновения бруска с поверхностью?**
*Ответ:* В рамках школьной модели — нет: Fтр = μN зависит от силы нормального давления и рода поверхностей, но не от площади опоры. Можно проверить экспериментально, повернув брусок на другую грань.

**5. Зависит ли работа силы трения от скорости равномерного движения?**
*Ответ:* Нет. Работа A = Fтр·s определяется силой трения и пройденным путём. Скорость влияет лишь на время движения (быстрее проедете путь — быстрее закончите работу), но не на её величину.
