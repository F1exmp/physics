# Справочник ученика. Урок №34. Механическая работа и мощность

## 1. Механическая работа

**Определение.** Механическая работа — физическая величина, равная произведению модуля силы на модуль перемещения и на косинус угла между направлением силы и направлением перемещения.

**Векторная форма:** A = F⃗ · s⃗ (скалярное произведение векторов силы и перемещения).

**Скалярная (расчётная) формула:**

A = F · s · cos α  [Дж]

Единица работы — **джоуль**: 1 Дж = 1 Н·м. Это работа силы 1 Н на перемещении 1 м по направлению силы.

### Знак работы зависит от угла α
| Угол α | cos α | Работа | Когда бывает |
|---|---|---|---|
| 0° | 1 | A = F·s > 0 | Сила по направлению движения (тяга, сила тяжести при падении) |
| 90° | 0 | A = 0 | Сила перпендикулярна перемещению (сила тяжести на горизонтальном участке, сила реакции опоры, центростремительная сила) |
| 180° | −1 | A = −F·s < 0 | Сила против движения (трение при движении, сила тяжести при подъёме) |

Правило запоминания: «Помогает движению — плюс, мешает — минус, ничуть не мешает (перпендикулярна) — ноль».

## 2. Мощность

**Определение.** Мощность — физическая величина, показывающая, какая работа совершается за единицу времени (скорость совершения работы).

**Основная формула:**

N = A / t  [Вт]

**Единица мощности — ватт:** 1 Вт = 1 Дж/с. Кратные: 1 кВт = 1000 Вт, 1 МВт = 10⁶ Вт.

**Полезная «транспортная» формула** (при равномерном движении, α = 0°):

N = F · v

Вывод: N = A/t = F·s/t = F·(s/t) = F·v. Чем больше сила тяги при той же мощности, тем меньше установившаяся скорость (и наоборот).

**Внесистемная единица — лошадиная сила:**

1 л.с. ≈ 735,5 Вт ≈ 0,735 кВт

## 3. Мощности из техники (ориентиры)

| Устройство | Мощность |
|---|---|
| Лампа накаливания | 60 Вт |
| Человек при быстрой ходьбе / подъёме по лестнице | ~100 Вт (пик до 500–1000 Вт) |
| Мотороллер / мопед | ~3–5 кВт |
| Легковой автомобиль | ~100 кВт (≈ 135 л.с.) |
| Грузовой тепловоз | ~2–3 МВт |
| Электровоз | ~5 МВт |
| Крупная ГЭС (турбина) | сотни МВт |

## 4. Алгоритм решения задач на работу и мощность

1. **Выяснить, какие силы действуют** и как направлены относительно перемещения.
2. **Записать «Дано»**, перевести единицы в СИ (минуты → секунды, т → кг, кН → Н, км → м).
3. **Определить угол α** между силой и перемещением (часто 0°, 90° или 180°).
4. **Вычислить работу** A = F·s·cosα. Если сила — это сила тяжести или упругости при равномерном подъёме, F = mg.
5. **Для мощности**: N = A/t; если даны сила и скорость, сразу N = F·v.
6. **Обратные задачи**: s = A/(F·cosα); F = A/s; t = A/N; N = A/t.
7. **Проверить ответ** на разумность (единицы, знак, порядок величины).

## 5. Ключевые формулы (шпаргалка)

- A = F·s·cosα [Дж], 1 Дж = 1 Н·м
- A тяжести при подъёме: A = −mgh; при опускании: A = +mgh
- N = A/t [Вт], 1 Вт = 1 Дж/с
- N = F·v (равномерное движение, сила по скорости)
- 1 л.с. ≈ 735,5 Вт

## 6. Мини-историческая справка
- **Джеймс Джоуль** (1818–1889) доказал опытами превращение работы в теплоту → его именем названа единица работы и энергии.
- **Джеймс Уатт** (1736–1819) ввёл «лошадиную силу» для сравнения паровых машин с лошадьми; его именем названа единица мощности — ватт.
