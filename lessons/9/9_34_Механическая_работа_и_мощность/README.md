## Ключевые формулы

```
Работа:    A = F · s · cos α        [A] = 1 Дж = 1 Н·м
Знаки:     α = 0° → A > 0;  α = 90° → A = 0;  α = 180° → A < 0
Мощность:  N = A / t  =  F · v      [N] = 1 Вт = 1 Дж/с
```
