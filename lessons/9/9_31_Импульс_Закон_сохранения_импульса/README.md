## Ключевые формулы

```
Импульс тела:      p = m · v        [кг·м/с]
Импульс силы:      F · Δt = Δp
Сохранение:        m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′
Неупругое:         m₁v₁ + m₂v₂ = (m₁ + m₂)·v′
Упругое (m1=m2):   шары обмениваются скоростями
```
