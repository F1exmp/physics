# Задачи «Ядерные реакции»

## Базовые задачи

**Задача 1.** Допишите реакцию: ²⁷₁₃Al + ⁴₂He → ? + ¹₀n.

**Задача 2.** Расшифруйте обозначения: p, n, ⁴₂He, e, γ.

**Задача 3.** Допишите реакцию: ⁹₄Be + ⁴₂He → ? + ¹₀n.

**Задача 4.** Допишите реакцию: ¹⁴₇N + ⁴₂He → ? + ¹₁H.

## Средние задачи

**Задача 5.** Допишите реакцию: ⁶₃Li + ¹₁H → ? + ?.

**Задача 6.** Допишите реакцию деления: ²³⁵₉₂U + ¹₀n → ¹⁴¹₅₆Ba + ? + 3¹₀n.

**Задача 7.** Допишите реакцию: ²⁴₁₂Mg + ⁴₂He → ? + ¹₁H.

## Повышенные задачи

**Задача 8.** Допишите реакцию: ²⁰⁹₈₃Bi + ⁴₂He → ? + 2¹₀n.

**Задача 9.** Допишите реакцию: ⁷₃Li + ¹₁H → ? + ?.

**Задача 10.** Допишите реакцию деления: ²³⁵₉₂U + ¹₀n → ¹⁴⁰₅₄Xe + ? + 2¹₀n.

---

## Ответы и решения

### Базовые

**Задача 1.** ²⁷₁₃Al + ⁴₂He → ³⁰₁₅P + ¹₀n.

**Задача 2.** p — протон, n — нейтрон, ⁴₂He — α-частица (ядро гелия), e — электрон (β-частица), γ — гамма-квант.

**Задача 3.** ⁹₄Be + ⁴₂He → ¹²₆C + ¹₀n.

**Задача 4.** ¹⁴₇N + ⁴₂He → ¹⁷₈O + ¹₁H.

### Средние

**Задача 5.** ⁶₃Li + ¹₁H → ⁴₂He + ³₂He.

**Задача 6.** ²³⁵₉₂U + ¹₀n → ¹⁴¹₅₆Ba + ⁹²₃₆Kr + 3¹₀n.

**Задача 7.** ²⁴₁₂Mg + ⁴₂He → ²⁷₁₃Al + ¹₁H.

### Повышенные

**Задача 8.** ²⁰⁹₈₃Bi + ⁴₂He → ²¹¹₈₅At + 2¹₀n.

**Задача 9.** ⁷₃Li + ¹₁H → ⁴₂He + ⁴₂He.

**Задача 10.** ²³⁵₉₂U + ¹₀n → ¹⁴⁰₅₄Xe + ⁹⁴₃₈Sr + 2¹₀n.
