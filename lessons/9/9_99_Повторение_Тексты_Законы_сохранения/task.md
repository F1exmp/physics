# Работа с текстом «Законы сохранения»

## Задания к тексту

1. Озаглавьте текст.
2. Ответьте на 5 вопросов по содержанию.
3. Проверьте утверждение по тексту.
4. Составьте план текста.
5. Приведите пример из жизни к каждому закону.

---

## Ответы/критерии

- Заголовок должен отражать суть (например, «Ничего не исчезает: законы сохранения»).
- Ответы строго по тексту с опорой на формулы.
- План: импульс → сохранение импульса → энергия → превращения → реактивное движение.
- Примеры: столкновения шаров; маятник; ракета.
