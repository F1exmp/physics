## Ключевые формулы

```
Равновесие точки:      ΣF = 0
Равновесие с осью:     ΣM = 0
Момент силы:           M = F × d   [Н·м]
Рычаг:                 F₁ × d₁ = F₂ × d₂
Центр тяжести:         xc = Σ(mi·xi) / Σmi
```
