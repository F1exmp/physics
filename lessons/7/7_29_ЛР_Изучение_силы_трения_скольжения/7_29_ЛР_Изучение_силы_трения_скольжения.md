## 2. Актуализация знаний (5-7 мин)

### Повторение перед работой

**Учитель:** Напомню технику измерения — она построена на вчерашнем материале.

1. **Как измерить силу трения скольжения?**
   - *Ответ:* Тянем брусок динамометром РАВНОМЕРНО. При равномерном движении R = 0, значит сила трения по модулю равна показанию динамометра: Fтр = Fтяги.

2. **Почему именно равномерно?**
   - *Ответ:* Если тянуть с ускорением, тяга больше трения (R ≠ 0), и показание динамометра завысит силу трения.

3. **Что такое сила нормального давления здесь?**
   - *Ответ:* Прижимающая сила. Для горизонтальной поверхности — вес бруска (вместе с грузами): N = g·m.

4. **Цена деления вашего динамометра?**
   - *Ответ:* Обычно 0,1 Н. Определите перед измерением и запишите.

5. **Техника безопасности?**
   - *Ответ:* Не размахивайте бруском и динамометром, аккуратно обращайтесь со стеклянными поверхностями (если есть), не роняйте грузы.

**Учитель:** Гипотезы нашего исследования записываем:
- Гипотеза 1: при увеличении прижимающей силы сила трения растёт.
- Гипотеза 2: на более шероховатой поверхности сила трения больше.
Проверим опытным путём!

## 3. Ход работы (25-28 мин)

### Часть 1. Измерение силы трения при разной нагрузке (одна и та же поверхность)

2. Измерьте Fтр при движении бруска по НАЖДАЧНОЙ бумаге (равномерно, 3 раза, среднее): Fтр(нажд.) = ______ Н.
3. Измерьте Fтр при движении бруска по ТКАНИ: Fтр(ткань) = ______ Н.

### Таблица измерений

**Часть 1 (поверхность — гладкая доска):**

| № опыта | Прижимающая сила N = вес, Н | Сила трения Fтр, Н |

Также установлено, что сила трения зависит от характера соприкасающихся поверхностей: на шероховатых поверхностях (ткань, наждачная бумага) трение больше, чем на гладких. Гипотезы 1 и 2 подтвердились.

## 4. Закрепление и обсуждение результатов (7-10 мин)

### Задача № 1 (обсуждение)

**1. Условие задачи.**
При движении бруска весом 3 Н по гладкой доске сила трения оказалась 0,6 Н. Какой будет сила трения, если на брусок положить груз весом 3 Н?

**2. Объяснение задачи.**
Прямое применение вывода ЛР: трение пропорционально прижимающей силе. Вес вырос с 3 Н до 6 Н — в 2 раза. Значит, трение тоже вырастет в 2 раза. Ученики должны увидеть связь с их собственными измерениями.

**3. Решение.**
```
Дано: N₁ = 3 Н → Fтр₁ = 0,6 Н; N₂ = 3 + 3 = 6 Н
N₂ / N₁ = 6 / 3 = 2
Fтр пропорциональна N → Fтр₂ = 0,6 × 2 = 1,2 Н
```
*Ответ:* Fтр = 1,2 Н.

### Задача № 2 (обсуждение)

**1. Условие задачи.**
Брусок тянут равномерно: динамометр показывает 0,8 Н. Ученик начал тянуть резче, показание подскочило до 1,1 Н. Что произошло с силой трения?

**2. Объяснение задачи.**
Ловушка на понимание метода! При рывке движение неравномерное — тяга уже больше трения, показание завышено. Настоящая сила трения — та, что при РАВНОМЕРНОМ движении: 0,8 Н. Именно поэтому в работе требуется равномерность.

**3. Решение.**
```
Равномерное движение: Fтр = 0,8 Н
При рывке: тяга 1,1 Н ≠ Fтр, часть тяги идёт на разгон
R = 1,1 − 0,8 = 0,3 Н — на ускорение бруска
Сила трения не изменилась: 0,8 Н
```
*Ответ:* сила трения осталась 0,8 Н; лишние 0,3 Н ушли на разгон.

### Задача № 3 (обсуждение)

**1. Условие задачи.**
Сравните силу трения бруска по ткани и по гладкой доске, если измерения дали 0,9 Н и 0,4 Н. Во сколько раз трение о ткань больше? Где это знание пригодится?

**2. Объяснение задачи.**
Простое отношение: 0,9/0,4 ≈ 2,25. Практическое значение: выбор материалов (например, протектор шин — «ткань против льда»), коврики, спортивная обувь. Связываем с уроком 28.

**3. Решение.**
```
Fтр(ткань) / Fтр(доска) = 0,9 / 0,4 ≈ 2,25
```
*Ответ:* примерно в 2,25 раза больше; используется при выборе материалов с нужным сцеплением (шины, обувь, тормоза).
