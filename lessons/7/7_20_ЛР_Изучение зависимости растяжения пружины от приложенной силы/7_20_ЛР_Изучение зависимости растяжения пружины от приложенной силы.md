# Урок 20. Лабораторная работа «Изучение зависимости растяжения пружины от приложенной силы»

**Класс:** 7
**Время:** 45 минут
**Цель урока:** экспериментально проверить пропорциональность растяжения пружины приложенной силе, построить график, найти жёсткость.

3. Построение графика F(Δl), вычисление k.
4. Оформление отчёта, выводы.

**Домашнее задание:** отчёт по работе.
