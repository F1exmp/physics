## Слайд 3
ТЕОРЕТИЧЕСКАЯ ОСНОВА
F = k × x
F — сила упругости (Ньютон, Н)
k — жёсткость пружины (Н/м)
x — растяжение пружины (метр, м)
Сила тяжести: F = m × g
g ≈ 9,8 м/с2 ≈ 10 м/с2 (для упрощения)
При равновесии: Fупругости = Fтяжести

## Слайд 8
ОБРАБОТКА ЭКСПЕРИМЕНТАЛЬНЫХ ДАННЫХ
1. Вычисление растяжения: x = L - L₀
2. Перевод единиц: мм → м (1 мм = 0,001 м)
3. Определение жёсткости из закона Гука: k = F / x
4. Построение графика F(x):
• Ось X — растяжение x (м)
• Ось Y — сила F (Н)
• Построить точки по данным
• Провести прямую через начало координат
5. Среднее значение: k₍ср₎ = (k₁ + k₂ + k₃ + k₄ + k₅) / 5

## Слайд 9
ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ
График — прямая линия через начало координат
Линейная зависимость: F ∝ x
Угловой коэффициент = жёсткость пружины k
k ≈ 50-200 Н/м (зависит от пружины)
Различия k < 10% — нормально
Отклонения — погрешности измерений
Типичный график F(x):
F (Н)
↑
│         •
│      •
│   •
│•
└────────→ x (м)
Подтверждение закона Гука:
F = k × x
