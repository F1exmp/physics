# Урок 65. Урок-эксперимент «Экспериментальное определение изменения кинетической и потенциальной энергии при скатывании тела по наклонной плоскости»

**Класс:** 7
**Тема урока:** Урок-эксперимент «Экспериментальное определение изменения кинетической и потенциальной энергии при скатывании тела по наклонной плоскости»
**Оборудование (на группу):**
- Наклонная плоскость (доска) на штативе
- Шарик (или деревянный цилиндр/тележка)
- Секундомер
- Линейка (или измерительная лента)
- Весы с разновесами
**Время:** 45 минут

---

## 1. Организационный момент (2-3 мин)

**Учитель:** Добрый день, ребята! Сегодня — урок-эксперимент. Мы своими измерениями проверим закон сохранения механической энергии: скатим шарик по наклонной плоскости и сравним, насколько уменьшилась его потенциальная энергия и насколько выросла кинетическая. Задача каждого — провести измерения аккуратно и честно, а затем обсудить, почему результаты не совпадают идеально.

**Цель урока:**
- Экспериментально измерить изменение потенциальной и кинетической энергии тела при скатывании
- Сравнить ΔE(п) и ΔE(к) и сделать вывод о законе сохранения энергии
- Научиться оценивать погрешности эксперимента

---

## 2. Актуализация знаний. Подготовка к эксперименту (5-7 мин)

### Вопросы для фронтального опроса:

1. **Как вычислить потенциальную энергию тела на высоте h?**
   - *Ответ:* E(п) = m·g·h.

2. **Как вычислить кинетическую энергию движущегося тела?**
   - *Ответ:* E(к) = m·v²/2.

3. **Сформулируйте закон сохранения механической энергии.**
   - *Ответ:* При отсутствии трения и сопротивления полная механическая энергия сохраняется.

4. **Как измерить скорость шарика у подножия наклонной плоскости с помощью секундомера?**
   - *Ответ:* Разогнать шарик, затем измерить время t прохождения известного пути s (например, 1 м) по горизонтальной части у подножия: v = s/t. (Обсуждение: скорость предполагается постоянной на горизонтальном участке с малым трением.)

5. **Что нам нужно измерить? Перечислим:**
   - *Ответ (составляем список):* массу шарика m, высоту стартовой точки h, время прохождения контрольного пути t, длину этого пути s.

### План эксперимента (обсуждаем с классом)

1. Взвесить шарик → m.
2. Установить наклонную плоскость, измерить высоту верхней точки над «нулевым уровнем» → h.
3. Скатить шарик; измерить время прохождения контрольного участка длиной s у подножия → t (3 раза, взять среднее).
4. Вычислить скорость у подножия: v = s/t(ср).
5. Вычислить потерю потенциальной энергии: ΔE(п) = m·g·h.
6. Вычислить прирост кинетической энергии: ΔE(к) = m·v²/2.
7. Сравнить ΔE(п) и ΔE(к); оценить долю «потерь».

---

## 3. Ход эксперимента (20-25 мин)

### Этап 1. Измерения

**Учитель:** Работаем группами по 3 человека: «взвешивающий» (весы), «секундометрист», «расчётчик». Скатывать шарик и запускать секундомер одновременно — важная операция, тренируйтесь до измерений!

1. Масса шарика: m = 100 г = 0,1 кг.
2. Высота наклонной плоскости: h = 0,3 м (верхний край над столом).
3. Контрольный участок у подножия: s = 1,0 м.
4. Время прохождения участка (3 попытки): t₁ = 1,3 с; t₂ = 1,4 с; t₃ = 1,3 с.
5. Среднее время: t(ср) = (1,3 + 1,4 + 1,3)/3 = 1,33 с (округляем до 1,33 с).

### Таблица измерений

| Величина | Обозначение | Значение |
|----------|-------------|----------|
| Масса шарика | m | 0,1 кг |
| Высота старта | h | 0,3 м |
| Контрольный путь | s | 1,0 м |
| Время (попытки) | t₁, t₂, t₃ | 1,3; 1,4; 1,3 с |
| Среднее время | t(ср) | 1,33 с |

### Этап 2. Обработка результатов (расчёты по шагам)

**Шаг 1. Скорость шарика у подножия:**
```
v = s / t(ср) = 1,0 м / 1,33 с ≈ 0,75 м/с
```

**Шаг 2. Потеря потенциальной энергии (m·g·h):**
```
ΔE(п) = m·g·h = 0,1 кг · 10 Н/кг · 0,3 м = 0,3 Дж
```

**Шаг 3. Прирост кинетической энергии (m·v²/2):**
```
ΔE(к) = m·v² / 2 = 0,1 кг · (0,75 м/с)² / 2
ΔE(к) = 0,1 · 0,5625 / 2 ≈ 0,028 Дж
```

**Шаг 4. Сравнение:**
```
ΔE(п) = 0,3 Дж;  ΔE(к) ≈ 0,03 Дж
ΔE(к) значительно МЕНЬШЕ ΔE(п)!
```

**Результат: нанос...** Не спешите с выводом! Такой большой разброс означает, что **методика недоучитывает движение по наклонной плоскости**: шарик вкатывается на горизонтальный участок уже имея скорость, но контрольный путь мы измеряем ПОСЛЕ его прохождения. Главная причина расхождения — **трение**: значительная часть потенциальной энергии перешла во внутреннюю энергию (нагревание) и в энергию вращения шарика.

**Шаг 5. Оценка «потерь»:**
```
Потери: ΔE(п) − ΔE(к) = 0,3 − 0,03 = 0,27 Дж
Доля, перешедшая в кинетическую энергию поступательного движения:
0,03 / 0,3 · 100 % = 10 %
Остальное: трение, вращение шарика, нагревание
```

### Таблица результатов

| Величина | Формула | Значение |
|----------|---------|----------|
| Потеря потенциальной энергии | ΔE(п) = m·g·h | 0,3 Дж |
| Скорость у подножия | v = s/t | ≈ 0,75 м/с |
| Прирост кинетической энергии | ΔE(к) = m·v²/2 | ≈ 0,03 Дж |
| Разность («потери») | ΔE(п) − ΔE(к) | ≈ 0,27 Дж |

### Этап 3. Обсуждение результатов

**Учитель:** Обсудим, почему ΔE(к) << ΔE(п):

1. **Куда ушла энергия?**
   - *Ожидаемый ответ:* на трение (нагревание шарика и плоскости) и на вращение шарика (у катящегося тела часть энергии — энергия вращения).
2. **Закон сохранения нарушился?**
   - *Ожидаемый ответ:* нет! Механическая энергия переходит во внутреннюю. Полная энергия сохраняется, но не вся стала кинетической энергией движения.
3. **Какие погрешности измерений влияют?**
   - *Ожидаемый ответ:* время реакции при включении секундомера; несовершенное измерение высоты; шарик мог катиться не по прямой.
4. **Как улучшить эксперимент?**
   - *Ожидаемый ответ:* использовать электронный секундомер или датчики скорости; уменьшить трение (гладкая плоскость, шарик на оси); повторить измерения больше раз.

### Вывод (примерный)

> При скатывании шарика по наклонной плоскости его потенциальная энергия уменьшилась на 0,3 Дж, а кинетическая энергия поступательного движения выросла лишь примерно на 0,03 Дж. Разница перешла во внутреннюю энергию (трение) и в энергию вращения шарика. Полная энергия сохраняется, но не вся механическая энергия превращается в кинетическую — это подтверждает закон сохранения энергии с учётом превращений энергии.

## 4. Закрепление (5-7 мин)

### Задача для закрепления

#### 1. Условие задачи

Если бы в нашем эксперименте трение отсутствовало полностью, какую скорость имел бы шарик массой 0,1 кг у подножия наклонной плоскости высотой 0,3 м?

#### 2. Объяснение задачи

Задача «наоборот»: применяем закон сохранения для идеального случая. m·g·h = m·v²/2 → v = √(2gh). Масса не нужна.

#### 3. Решение

*Дано:*
- h = 0,3 м
- g = 10 Н/кг

*Найти:*
- v — ?

*Решение:*
```
m·g·h = m·v² / 2
v = √(2·g·h) = √(2 · 10 · 0,3) = √6 ≈ 2,4 м/с
```

*Ответ:* В идеальном (без трения) случае v ≈ 2,4 м/с. В нашем опыте получилось ≈ 0,75 м/с — разница и показывает потери энергии на трение и вращение.
