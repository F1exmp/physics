```
📍 Обозначение силы: F (фэ)

📍 Единицы измерения:
• Ньютон (Н)
• 1 Н = сила, которая сообщает телу
  массой 1 кг ускорение 1 м/с²
```

**Визуальные элементы:**
- Иллюстрация руки толкает тележку (вектор F показывает направление силы)
- Иллюстрация магнит притягивает железный шарик
- Иллюстрация一书 (книга) давит на стол (вектор силы вниз)

**Примечание для учителя:**
- Объяснить аналогию: "Представьте, что сила — это 'толчок' или 'растягивание', которое одно тело оказывает на другое"

*Простые объяснения:*

**Как взаимодействуют тела:**
- Когда тела взаимодействуют, они испытывают действие друг на друга
- Это всегда взаимно: если тело А толкает тело Б, то и тело Б толкает тело А (в обратную сторону!)
- Это называется третьим законом Ньютона (можно сказать, что "действие равно противодействию")

**Всегда ли есть банка взаимодействия:**
- Взаимодействие возникает только при близком контакте тел (близость зависит от типа силы)
- Например, гравитационное взаимодействие действует на расстоянии, а упругое — только при контакте

- Заметьте: сила — это **не** вещество, которое хранится в теле, это **процесс взаимодействия**
- Сила имеет величину (сколько Ньютонов?) и направление (куда pushed?)

## СЛАЙД №6: Сила упругости

**Заголовок:**
```
Сила упругости
```

**Основное содержание:**
```
Сила упругости — это сила,
возникающая при деформации тела
и стремящаяся вернуть его
в первоначальное состояние.

Деформация — изменение формы или размера тела
```

**Примеры из жизни:**

```
📍 Сжатая пружина → хочет разжаться
📍 Растянутая резинка → хочет стянуться
📍 Согнутая линейка → хочет выпрямиться
📍 Смятый мяч → хочет стать круглым
```

**Визуальные элементы:**
- Большая иллюстрация пружины (сжатой)
- Стрелки показывают, в какую direction силы упругости действует
- Для каждого примера маленькая картинка

**Примечание для учителя:**

*Более глубокое объяснение:*

**Деформация — это:**
- Любое изменение формы или размера тела
- Бывает растяжение, сжатие, изгиб, кручение, сдвиг

**Особенности силы упругости:**
1. Возникает **только** при деформации
2. Всегда направлена **против деформации** (в сторону первоначальной формы)
3. Силы упругости **сопротивляются** деформации

*Почему она возникает?*
- Все тела состоят из атомов
- При деформации атомы отодвигаются друг от друга или сближаются
- Возникают взаимодействия между атомами, которые "не дают" телу остаться деформированным
- Силы между атомами и создают упругую силу

**Демонстрация на уроке:**
*Обязательно показать наглядно:*
- Сжать пружину в руках, показывая стрелки силы
- Растянуть резинку и показать, как она тянет обратно
- Согнуть деревянную линейку и показать, как она пытается выпрямиться

*Вопрос ученикам:*
- "Почему сжатая пружина сила толкает наружу?"
- "Куда направлена сила упругости в каждом случае?"

*Ответ:*
- Сила всегда направлена против деформации
- В сжатой пружине — наружу (стремится разжаться)
- В растянутом шнурке — внутрь (стремится растянуться)

## СЛАЙД №7: Закон Гука

**Заголовок:**
```
Закон Гука
```

**Основное содержание:**

**Формула закона Гука:**
```
F = k · x

Где:
F — сила упругости (Н)
k — жёсткость пружины (Н/м)
x — удлинение (сжатие) пружины (м)
```

**Правило:**
```
Сила упругости прямо пропорциональна
деформации тела!
```

**График:**
```
На графике: прямая, проходящая через начало координат

      F
      │
      │      /
      │     /
      │    /
      │   /
      │  /
      │ /
      │/
      └───── x
```

**Визуальные элементы:**
- Большая формула по центру
- График функции F = kx
- Маленькая иллюстрация: пружина с указанием удлинения x
- Таблица: что означает каждая переменная

**Комментарий к графику:**
```
Если удлинение увеличивается в 2 раза,
сила упругости тоже увеличивается в 2 раза!
```

**Примечание для учителя:**

*Подробное объяснение формулы:*

**Каждая переменная:**

*F (сила упругости)*
- Измеряется в Ньютонах (Н)
- Это величина силы, которая стремится вернуть тело в исходное состояние

*k (жёсткость пружины)*
- Измеряется в Н/м (Ньютон на метр)
- Показывает, насколько упругое тело "сопротивляется" деформации
- Чем больше k, тем сильнее сила при той же деформации
- Например: стальная пружина (k большой) жестче резинки (k маленький)

*x (удлинение/сжатие)*
- Измеряется в метрах (м)
- Показывает, на сколько изменилась длина пружины
- Сжатие считается положительным, растяжение — тоже положительным (опускаем знак)
- Важно: x — это изменение длины, а не сама длина!

**Визуализация с пружиной:**
- Пусть L₀ — начальная длина пружины
- L — новая длина после деформации
- Тогда x = |L - L₀| — величина деформации (удлинение по модулю)

*Интерпретация закона:*
"Чем сильнее сжать пружину (больше x), тем сильнее она倒霉 толкает (больше F)"

*Вопрос для учеников:*
- "Если x = 0 м (пружина не деформирована), чему равна F?"
- *Ответ: F = 0 Н (силы нет!)*

- "Если x увеличить в 2 раза, во сколько раз увеличится F?"
- *Ответ: В 2 раза тоже (прямая пропорциональность)*

**Графический метод:**
- График — прямая через начало координат
- Жёсткость k — это наклон графика (угловой коэффициент)
- Чем круче график, тем больше k (жёстче пружина)

**Практическое значение закона:**
- Используется в инженерии (амортизаторы, подвески)
- Позволяет предсказывать, как будет вести себя упругое тело
- Важен для расчёта пружин в часах, матрасах, автодеталях_WEAPON

## СЛАЙД №8: Историческая справка

**Заголовок:**
```
Открыватель закона Гука — Роберт Гук
```

**Основное содержание:**

**Биография (1635–1703):**
```
🎓 Роберт Гук — английский учёный,
    один из величайших экспериментаторов эпохи

💡 Родился в семье священника на острове Уайт
💡 Изучал медицину в Оксфорде
💡 Был ассистентом Роберта Бойля (открывателя закона Бойля-Мариотта)
💡 Секретарь Лондонского королевского общества (главная научная организация)
```

**Интересные факты о Гуке:**
```
✓ Открыл закон упругости в 1660 году

✓ Изобрёл первый телескоп и открыл клетки растений
  (он дал им название "клетки", потому что они напоминают
   кельи монахов)

✓ Впервые сформулировал закон всемирного тяготения

✓ Был инженером, который восстанавливал Лондон
  после великого пожара 1666 года

✓ Всего опубликовал более 700 научных работ!
```

**История открытия закона Гука:**

```
📜 В 1660 году Гук проводил эксперименты с пружинами

📜 Он заметил: сжатая пружина толкает сильнее,
   если её сильнее сжать

📜 Он измерил, что сила прямо пропорциональна
   деформации

📜 Сначала он сформулировал закон словами:
   "Ut tensio, sic vis"
   (лат.: "Какое растяжение, такая и сила")

📜 Позднее закон получил математическую форму:
   F = kx
```

**Визуальные элементы:**
- Портрет Роберта Гука
- Иллюстрация: скнилинг пружины в лаборатории
- Надпись: "Ut tensio, sic vis" с переводом
- Формула F = kx

**Примечание для учителя:**

*Более подробная историческая справка (для интересных сообщений):*

**Как проходил эксперимент Гука:**
- Гук использовал пружины разных типов и металлов
- Он подвешивал к ним грузы и измерял длину пружины
- Замечал, что каждый ньютоны груза увеличивают длину на одинаковую величину
- Это было первым экспериментальным доказательством закона

**Почему "Ut tensio, sic vis" (Какое растяжение, такая и сила):**
- Гук выбрал эти слова, чтобы выразить простую идею: величина силы пропорциональна деформации
- Латинский язык использовался как международный научный язык того времени

**Конфликт с Ньютоном:**
- Гук первым сформулировал закон всемирного тяготения (1641 г.)
- Но считал, что он применим только к небесным телам
- Ньютон затем показал, что этот закон действует для всех законов
- Между ними был спор за авторство

**Личность Гука:**
- Был невероятно плодовитым изобретателем (изобрёл микроскоп, телескоп, часы маятника)
- Интересовался искусством, архитектурой, музыкой
- Он восстанавливал Лондон после пожара, проектировал новые здания
- Умер в возрасте 68 лет, завещав значительное количество денег науке

**Подключение к уроку:**
- Спросить: "Как вы думаете, почему учёный интересуется пружинами?"
- *Ответ:* Понимание упругости открывало путь к пониманию механики, создании механизмов, часы, амортизаторы

- Вопрос: "Почему закон Гука так важен в инженерии?"
- *Ответ:* Он позволяет проектировать механизмы, предсказывать поведение материалов

### Задача №1 (Базовая)

**Основное содержание:**
```
Задача №1: Базовая

Условие:
Пружину сжали на 5 см.
Жёсткость пружины 200 Н/м.
Найдите силу упругости.
```

**Решение (пошагово):**
```
Дано:
x = 5 см = 0,05 м
k = 200 Н/м

Найти:
F — ?

Решение:
F = k · x
F = 200 Н/м · 0,05 м
F = 10 Н

Ответ: Сила упругости равна 10 Н.
```

**Визуальные элементы:**
- Рисунок пружины с указанием деформации x = 5 см
- Стрелка силы F направлена против деформации
- Таблица с переводом единиц (5 см → 0,05 м)

**Примечание для учителя:**
- Комментарий: "Обратите внимание: важно перевести сантиметры в метры!"
- Вопрос: "Почему ответ в Ньютонах, а не в других единицах?"
- *Ответ:* В формуле k в Н/м, x в м, умножение даст Н

### Задача №2 (Средняя сложность)

**Основное содержание:**
```
Задача №2: Средняя сложность

Условие:
К пружине с жёсткостью 300 Н/м подвесили груз массой 6 кг.
Как растянулась пружина?
(Ускорение свободного падения g = 10 м/с²)
```

**Решение (пошагово):**
```
Анализ:
Когда груз висит на пружине,
силы, действующие на груз, уравновешены:
Fупр = Fтяжести

1. Находим силу тяжести:
Fтяж = m · g
Fтяж = 6 кг · 10 м/с²
Fтяж = 60 Н

2. По закону Гука:
Fупр = k · x
60 Н = 300 Н/м · x
x = 60 Н / 300 Н/м
x = 0,2 м = 20 см

Ответ: Пружина растянулась на 20 см.
```

**Визуальные элементы:**
- Рисунок: вертикальная пружина с подвешенным грузом 6 кг
- Стрелки: сила тяжести вниз, сила упругости вверх
- Указание равенства: Fупр = Fтяж

**Примечание для учителя:**

*Важный момент:*
- Эта задача требует понимания, что когда груз висит в покое на пружине, сила упругости уравновешивает силу тяжести
- Поэтому Fупр = Fтяж

*Вопросы для учеников:*
- "Какие силы действуют на груз?"
- *Ответ:* Сила тяжести вниз, сила упругости вверх (от пружины)

- "Почему груз не падает?"
- *Ответ:* Силы равны и противоположны по направлению

*Методическое замечание:*
- Это хороший пример применения закона Гука в комбинации с силой тяжести
- Учитывать то, что сила упругости направлена против деформации (вверх, если пружина растягивается вниз)

**Дополнительный пример (устный)**:
"Если бы жёсткость пружины была 600 Н/м, то растяжение было бы..."
*Ответ: В 2 раза меньше, то есть 10 см (прямо пропорционально зависимости)*
