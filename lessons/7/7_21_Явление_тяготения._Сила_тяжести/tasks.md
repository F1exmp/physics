# Задачи к уроку №21: Явление тяготения. Сила тяжести

---

## Задача №1 (Базовая)

### Условие задачи

Найти силу тяжести для тела массой 5 кг.

### Объяснение задачи

Здесь требуется применить основную формулу силы тяжести Fт = m·g. Дано значение массы тела, а ускорение свободного падения g мы принимаем равным 10 Н/кг для упрощения (или 9,8 Н/кг для более точного расчета). Необходимо подставить значения и вычислить искомую силу.

### Решение

**ДАНО:**
- Масса тела: m = 5 кг
- Ускорение свободного падения: g = 10 Н/кг

**НАЙТИ:**
- Сила тяжести: Fт = ?

**РЕШЕНИЕ:**

1. Запишем формулу силы тяжести:
   ```
   Fт = m · g
   ```

2. Подставим известные значения:
   ```
   Fт = 5 кг · 10 Н/кг
   ```

3. Произведем вычисление:
   ```
   Fт = 50 Н
   ```

**ОТВЕТ:** Сила тяжести составляет 50 Н.

## Задача №2 (Средняя)

### Условие задачи

Масса автомобиля 1500 кг. Найти силу тяжести.

### Объяснение задачи

Эта задача требует применить формулу Fт = m·g для реального объекта — автомобиля. Масса significantly больше, чем в предыдущей задаче, поэтому можно ожидать значительно большее значение силы тяжести. Для повышения точности используем g = 9,8 Н/кг. Результат можно записать в ньютонах или перевести в килоньютоны (кН) для удобства записи.

### Решение

**ДАНО:**
- Масса автомобиля: m = 1500 кг
- Ускорение свободного падения: g = 9,8 Н/кг

**НАЙТИ:**
- Сила тяжести: Fт = ?

**РЕШЕНИЕ:**

1. Запишем формулу силы тяжести:
   ```
   Fт = m · g
   ```

2. Подставим известные значения:
   ```
   Fт = 1500 кг · 9,8 Н/кг
   ```

3. Произведем вычисление (используем метод разложения):
   ```
   Fт = 1500 · (10 - 0,2) Н
   Fт = 15000 Н - 300 Н
   Fт = 14700 Н
   ```

4. Перевод в килоньютоны (опционально):
   ```
   Fт = 14,7 кН (так как 1 кН = 1000 Н)
   ```

**ОТВЕТ:** Сила тяжести составляет 14700 Н ≈ 14,7 кН.

## Задача №3 (Повышенная)

### Условие задачи

На тело действует сила тяжести 490 Н. Найти массу тела.

### Объяснение задачи

Это обратная задача по сравнению с первыми двумя. Здесь известна сила тяжести, а нужно определить массу. Используется та же формула Fт = m·g, но теперь требуется выразить массу: m = Fт / g. Необходимо правильно выразить неизвестную величину из формулы и провести вычисления с учетом единиц измерения. При делении Ньютонов на Н/кг должны получить килограммы.

### Решение

**ДАНО:**
- Сила тяжести: Fт = 490 Н
- Ускорение свободного падения: g = 9,8 Н/кг

**НАЙТИ:**
- Масса тела: m = ?

**РЕШЕНИЕ:**

1. Запишем формулу силы тяжести:
   ```
   Fт = m · g
   ```

2. Выразим массу тела из формулы. Для этого разделим обе части на g:
   ```
   m = Fт / g
   ```

3. Проверим единицы измерения:
   ```
   [м] = [Н] / ([Н]/[кг]) = [кг]
   ```
   Единицы измерения совпадают, расчет правилен.

4. Подставим известные значения:
   ```
   m = 490 Н / 9,8 Н/кг
   ```

5. Произведем вычисление (можно удобным способом):
   ```
   m = 490 / 9,8
   m = 4900 / 98
   m = 50 кг
   ```

**ОТВЕТ:** Масса тела составляет 50 кг.

### Задача №7 (Сравнительная)

**Условие:** Сравнить силы тяжести, действующие на два тела массой 8 кг и 12 кг. На сколько сила тяжести больше для второго тела?

**РЕШЕНИЕ:**

1. Fт₁ = m₁ · g = 8 кг · 10 Н/кг = 80 Н
2. Fт₂ = m₂ · g = 12 кг · 10 Н/кг = 120 Н
3. Разница: ΔFт = Fт₂ - Fт₁ = 120 Н - 80 Н = 40 Н

**ОТВЕТ:** Разница составляет 40 Н.

## Ключевые моменты при решении задач

1. **Формула силы тяжести:**
   - Fт = m · g — всегда используйте эту формулу
   - Fт — сила тяжести (ньютон, Н)
   - m — масса тела (килограмм, кг)
   - g — ускорение свободного падения (Н/кг)

2. **Значение g:**
   - g = 9,8 Н/кг — точное значение для Земли
   - g ≈ 10 Н/кг — приближенное значение для упрощения расчетов

3. **Обратная задача:**
   - Если нужно найти массу, выразите её: m = Fт / g

4. **Единицы измерения:**
   - Всегда проверяйте единицы измерения результата
   - Н = кг · (Н/кг)
   - кг = Н / (Н/кг)
   - 1 кН = 1000 Н

5. **Перевод в большие единицы:**
   - Для больших значений (>1000 Н) используйте кН (килоньютоны)
   - Так результаты выглядят нагляднее
