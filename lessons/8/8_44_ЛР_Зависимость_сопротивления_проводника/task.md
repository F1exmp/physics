# Задания к ЛР «Зависимость сопротивления проводника»

## Подготовительные вопросы

1. По какой формуле считают сопротивление проводника?
2. Как измерить сопротивление экспериментально?

## Обработка результатов

Для каждой серии вычислите R = U/I и заполните таблицу. Проверьте:
- при удвоении длины R удвоилось?
- при удвоении сечения R уменьшилось вдвое?
- R нихрома >> R меди (во сколько раз)?

## Контрольные вопросы

**Вопрос 1.** Почему для опытов берут нихром, а не медь?

**Вопрос 2.** Почему надо измерять и ток, и напряжение, а не только ток?

---

## Ответы

**Ответ 1:** R = ρ·L/S.
**Ответ 2:** R = U/I — по закону Ома для участка (или по показаниям приборов).
**Ответ 1 (контроль):** у нихрома большое удельное сопротивление — при малой длине получается заметное измеримое R; у меди R очень мало, погрешность велика.
**Ответ 2:** R = U/I — нужно отношение двух величин; один ток не даёт информации о сопротивлении.
