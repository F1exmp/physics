## 3. Объяснение нового материала (15-18 мин)

### Плавление и отвердевание

**Плавление** — переход вещества из твёрдого состояния в жидкое. **Отвердевание (кристаллизация)** — обратный переход.

Ключевые факты:
- Кристаллические тела плавятся при строго определённой температуре — **температуре плавления**
- Пока идёт плавление, температура тела НЕ меняется: всё тепло идёт на разрушение кристаллической решётки
- Температуры плавления и отвердевания равны (у льда 0 °C, у олова 231,9 °C, у свинца 327 °C)
- Аморфные тела не имеют температуры плавления — размягчаются постепенно

**Демонстрация:** лёд в стакане на тёплой воде: смесь лёд+вода держится на 0 °C до полного таяния.

### Объяснение через МКТ

При плавлении частицы получают энергию, их колебания становятся такими сильными, что порядок решётки разрушается — частицы получают возможность перескакивать с места на место. Средняя скорость (и температура) не растёт — подводимая энергия увеличивает потенциальную энергию взаимодействия частиц.

При отвердевании наоборот: частицы «оседают» в решётку, потенциальная энергия уменьшается, и энергия выделяется — тело отдаёт теплоту при той же температуре.

### Удельная теплота плавления

**Удельная теплота плавления (λ)** — количество теплоты, необходимое для плавления 1 кг кристаллического вещества при температуре плавления.

Единицы: Дж/кг.

- Лёд: λ = 3,4·10⁵ Дж/кг (очень много — 340 кДж на кг!)
- Олово: 0,59·10⁵; свинец: 0,25·10⁵

**Формулы:**
- Плавление: Q = λ·m
- Отвердевание: Q = −λ·m (выделяется такое же количество теплоты)

## 4. Закрепление: решение задач (12-14 мин)

**Задача 1.** Какое количество теплоты нужно для плавления 2 кг льда при 0 °C?
Решение: Q = λ·m = 3,4·10⁵·2 = 6,8·10⁵ Дж = 680 кДж.

**Задача 2.** При отвердевании 500 г свинца выделилась теплота. Найдите её.
Решение: Q = λ·m = 0,25·10⁵·0,5 = 12,5 кДж.

**Задача 3.** Какую массу олова можно расплавить, затратив 29,5 кДж?
Решение: m = Q/λ = 29 500/59 000 = 0,5 кг.
