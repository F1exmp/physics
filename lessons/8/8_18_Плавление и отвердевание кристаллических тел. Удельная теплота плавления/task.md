# Задачи по теме «Плавление и отвердевание кристаллических тел. Удельная теплота плавления»

(λ льда = 3,4·10⁵ Дж/кг, λ олова = 0,59·10⁵ Дж/кг, λ свинца = 0,25·10⁵ Дж/кг)

## Базовые задачи

**Задача 1.** Что происходит с температурой кристаллического тела во время плавления?

**Задача 2.** Какое количество теплоты нужно для плавления 2 кг льда при 0 °C?

**Задача 3.** При отвердевании 500 г свинца выделяется… Найдите Q.

## Средние задачи

**Задача 1.** Сколько энергии нужно, чтобы расплавить 300 г олова, взятого при температуре плавления?

**Задача 2.** На что расходуется подводимая теплота при плавлении, если температура тела не растёт?

**Задача 3.** Для плавления льда при 0 °C израсходовано 1,7 МДж. Найдите массу льда.

## Повышенные задачи

**Задача 1.** Почему аморфные тела не имеют температуры плавления?

**Задача 2.** В калориметре 1 кг воды при 20 °C. Сколько льда при 0 °C нужно добавить, чтобы получить воду при 5 °C? (Считайте, что весь лёд расплавится.)

---

## Ответы

### Базовые
**Ответ 1:** остаётся постоянной, равной температуре плавления, всё тепло идёт на разрушение кристаллической решётки.
**Ответ 2:** Q = λ·m = 3,4·10⁵·2 = 6,8·10⁵ Дж = 680 кДж.
**Ответ 3:** Q = 0,25·10⁵·0,5 = 12 500 Дж = 12,5 кДж.

### Средние
**Ответ 1:** Q = 0,59·10⁵·0,3 = 17 700 Дж = 17,7 кДж.
**Ответ 2:** на разрушение кристаллической решётки — увеличение потенциальной энергии взаимодействия частиц, средняя скорость (температура) не меняется.
**Ответ 3:** m = Q/λ = 1,7·10⁶/3,4·10⁵ = 5 кг.

### Повышенные
**Ответ 1:** у аморфных тел нет строгой кристаллической решётки — нет и «момента её разрушения»; они постепенно размягчаются в интервале температур.
**Ответ 2:** лёд: плавление λ·m + нагрев воды c·m·(5−0); вода: остывание c·1·(20−5). Уравнение: 340000·m + 4200·5·m = 4200·15 → 361000·m = 63000 → m ≈ 0,17 кг.
