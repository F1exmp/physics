# Задания к резервному уроку «Работа с текстами: постоянный ток»

## Задания к тексту

1. Озаглавьте текст.
2. Ответьте на вопросы по содержанию текста (5 штук).
3. Проверьте утверждение по тексту: «электроны движутся со скоростью света».
4. Составьте план текста.
5. Напишите мини-эссе (3–4 предложения) по безопасности на основе чисел из текста.

## Дополнительное задание

Найдите в тексте все числовые данные и объясните, что означает каждое.

---

## Ответы/критерии

- Заголовок должен отражать главную мысль (например: «Ток в металлах и защита человека»).
- Ответы — только на основе текста, с опорой на числа.
- Утверждение неверно: дрейф электронов мал (доли мм/с), мгновенно распространяется лишь поле.
- План должен отражать структуру: 1) ток в металлах; 2) скорость дрейфа; 3) измерение тока; 4) опасность для человека; 5) УЗО.
- В эссе должны фигурировать числа: 50–100 мА опасны, УЗО срабатывает при нескольких мА.
