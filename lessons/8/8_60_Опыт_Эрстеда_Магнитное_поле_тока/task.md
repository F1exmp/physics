# Задания по теме «Опыт Эрстеда. Поле тока»

## Базовые задания

**Задание 1.** Что показал опыт Эрстеда?

**Задание 2.** Какой формы линии поля вокруг прямого провода с током?

**Задание 3.** Как определить полюса катушки с током?

## Средние задания

**Задание 1.** Почему витки катушки усиливают поле по сравнению с прямым проводом?

**Задание 2.** Сформулируйте правило буравчика и правило правой руки для соленоида.

**Задание 3.** Начертите линии поля: а) прямого тока; б) катушки с током.

## Повышенные задания

**Задание 1.** Как изменится поле катушки, если: а) увеличить ток; б) добавить витки; в) вставить железный сердечник?

**Задание 2.** Почему катушка с током, подвешенная на нити, разворачивается как стрелка компаса?

---

## Ответы

### Базовые
**Ответ 1:** вокруг проводника с током существует магнитное поле — ток отклоняет магнитную стрелку.
**Ответ 2:** концентрические окружности вокруг провода.
**Ответ 3:** по правилу правой руки для соленоида: пальцы по току в витках, большой палец указывает на N-полюс.

### Средние
**Ответ 1:** поля отдельных витков складываются (принцип суперпозиции) — внутри катушки все поля направлены одинаково.
**Ответ 2:** буравчик: большой палец по току — пальцы по линиям; правая рука для соленоида: пальцы по току — большой палец на N.
**Ответ 3:** а) окружности вокруг провода; б) замкнутые линии, снаружи похожи на поле полосового магнита.

### Повышенные
**Ответ 1:** а) поле усилится (пропорционально току); б) усилится (больше витков); в) многократно усилится (железо концентрирует линии поля).
**Ответ 2:** катушка с током — это магнит с N и S; в поле Земли разноимённые полюса притягиваются, и катушка устанавливается вдоль магнитных линий Земли, как стрелка.
