## Слайд 4. Ханс Кристиан Эрстед

**Левая колонка:**
- Эрстед (1777–1851), Дания
- 1820: во время лекции заметил отклонение компаса
- Открыл связь электричества и магнетизма

**Правая колонка:**
- Опыт:
- провод над стрелкой
- замкнули ток — стрелка отклонилась!
- магнит и ток «родственники»

## Слайд 5. Поле прямого тока

- Линии — концентрические окружности
- Правило буравчика (правой руки):
- большой палец по току → пальцы по линиям

## Слайд 6. Катушка с током (соленоид)

- Поля витков складываются
- Внутри — сильное однородное поле
- Снаружи — как у полосового магнита
- Есть N и S полюса
- Правило правой руки: пальцы по току → большой палец на N
