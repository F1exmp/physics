# Задачи по теме «КПД теплового двигателя»

(q бензина = 4,6·10⁷ Дж/кг, q угля = 3·10⁷ Дж/кг)

## Базовые задачи

**Задача 1.** Двигатель получил 3 МДж теплоты и совершил работу 900 кДж. Найти КПД.

**Задача 2.** КПД двигателя 20%. Сколько теплоты он получит, чтобы совершить работу 1 МДж?

## Средние задачи

**Задача 1.** Двигатель израсходовал 2 кг бензина и совершил работу 18,4 МДж. Найти КПД.

**Задача 2.** Сколько угля нужно сжечь, чтобы двигатель с КПД 30% совершил работу 90 МДж?

## Повышенные задачи

**Задача 1.** Почему невозможно построить тепловой двигатель с КПД 100%? Объясните роль холодильника.

**Задача 2.** Два двигателя: первый сжигает 1 кг бензина с КПД 35%, второй — 1 кг угля с КПД 45%. Какой совершит большую работу?

---

## Ответы

### Базовые
**Ответ 1:** η = 900/3000·100% = 30%.
**Ответ 2:** Q₁ = A/η = 1/0,2 = 5 МДж.

### Средние
**Ответ 1:** Q₁ = q·m = 4,6·10⁷·2 = 92 МДж; η = 18,4/92·100% = 20%.
**Ответ 2:** Q₁ = A/η = 90/0,3 = 300 МДж; m = 300/30 = 10 кг.

### Повышенные
**Ответ 1:** часть энергии обязательно передаётся холодильнику (отработанный пар/газы) — иначе рабочее тело не сможет вернуться в исходное состояние цикла; Q₂ нельзя свести к нулю.
**Ответ 2:** бензин: A = 0,35·4,6·10⁷ = 16,1 МДж; уголь: A = 0,45·3·10⁷ = 13,5 МДж. Первый двигатель больше (у бензина выше q).
