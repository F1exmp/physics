**Текст на слайде:**
# Повторение: Температура и внутренняя энергия

**Температура**
- Показывает тепловое состояние тела
- Измеряется в °C или K
- При повышении температуры молекулы движутся быстрее

**Внутренняя энергия**
- Сумма кинетической энергии всех молекул тела
- Зависит от температуры
- При нагревании: внутренняя энергия ↑
- При охлаждении: внутренняя энергия ↓

## Слайд 5. Количество теплоты

**Основная мысль:**
Введем понятие количества теплоты

**Визуальные элементы:**
- Формула Q = cmΔt крупным шрифтом
- Стрелки показывают направление теплоты от нагретого тела к холодному

**Текст на слайде:**
# Количество теплоты

**Определение:**
Количество теплоты — это энергия, которую тело получает или отдает при теплопередаче.

**Обозначение:** Q

**Единица измерения:** Джоуль (Дж)

**Знак Q:**
- При нагревании: Q > 0 (тело получает теплоту)
- При охлаждении: Q < 0 (тело отдает теплоту)

## Слайд 6. Удельная теплоемкость

**Основная мысль:**
Удельная теплоемкость — свойство вещества

**Визуальные элементы:**
- Сравнение нагревания 1 кг воды, железа и алюминия
- График линейной зависимости Q от Δt для разных веществ

**Текст на слайде:**
# Удельная теплоемкость

**Определение:**
Удельная теплоемкость (c) — это физическая величина, показывающая, какое количество теплоты необходимо для нагревания 1 кг вещества на 1°C.

**Обозначение:** c

**Единица измерения:** Дж/(кг·°C)

**Физический смысл:**
Если c = 4200 Дж/(кг·°C), значит для нагревания 1 кг воды на 1°C нужно 4200 Дж теплоты.

## Слайд 8. Формула количества теплоты

**Основная мысль:**
Основная формула для расчетов

**Визуальные элементы:**
- Формула Q = cm(t₂ - t₁) крупным шрифтом
- Объяснение каждого символа

**Текст на слайде:**
# Формула количества теплоты

**Q = cm(t₂ - t₁)**

или

**Q = cmΔt**

Где:
- **Q** — количество теплоты, Дж
- **c** — удельная теплоемкость, Дж/(кг·°C)
- **m** — масса тела, кг
- **t₁** — начальная температура, °C
- **t₂** — конечная температура, °C
- **Δt = t₂ - t₁** — изменение температуры, °C

---

## Слайд 9. Нагревание vs Охлаждение

**Основная мысль:**
Различия знаков при нагревании и охлаждении

**Визуальные элементы:**
- Схема процесса нагревания: тело получает энергию (Q > 0)
- Схема процесса охлаждения: тело отдает энергию (Q < 0)

**Текст на слайде:**
# Нагревание и охлаждение

**При нагревании:**
- Тело получает теплоту: Q > 0
- t₂ > t₁
- Δt > 0
- Энергия переходит к телу

**При охлаждении:**
- Тело отдает теплоту: Q < 0
- t₂ < t₁
- Δt < 0
- Энергия переходит от тела к окружению

## Слайд 11. Пример задачи 1 (нагревание воды)

**Основная мысль:**
Показать решение базовой задачи

**Визуальные элементы:**
- Чайник с водой
- График зависимости температуры от времени

**Текст на слайде:**
# Пример задачи 1

**Условие:**
Вычислите количество теплоты, необходимое для нагревания 2 литров воды от 10°C до 80°C.

**Решение:**
- m = V·ρ = 2 л · 1 кг/л = 2 кг
- Δt = 80°C - 10°C = 70°C
- Q = cmΔt = 4200 · 2 · 70 = 588 000 Дж

**Ответ:** Q = 588 кДж

## Слайд 12. Пример задачи 2 (смешивание)

**Основная мысль:**
Уравнение теплового баланса

**Визуальные элементы:**
- Схема смешивания двух порций воды
- Стрелки теплоты от горячей к холодной

**Текст на слайде:**
# Пример задачи 2 (смешивание)

**Условие:**
300 г воды при 80°C смешивают с 200 г воды при 20°C. Какая температура установится?

**Законы:**
- Горячая вода отдает тепло: Q₁ = cm₁(t - t₁)
- Холодная вода получает тепло: Q₂ = cm₂(t - t₂)
- Закон сохранения: Q₁ + Q₂ = 0

**Решение:**
- t = (m₁t₁ + m₂t₂) / (m₁ + m₂)
- t = (0,3·80 + 0,2·20) / (0,3 + 0,2) = 56°C

**Ответ:** t = 56°C

- Сравнение нагревания воды и металла

**Текст на слайде:**
# Почему вода имеет высокую теплоемкость?

**Причина:**
- Водородные связи между молекулами
- Мало энергии уходит на нагревание — много нужно для разрыва связей

**Практическое значение:**
- Вода долго нагревается и медленно остывает
- Используется в системах отопления и охлаждения
- Регулирует климат на Земле

**Сравнение:**
- Вода: c = 4200 Дж/(кг·°C)
- Железо: c = 460 Дж/(кг·°C) — в 9 раз меньше!
