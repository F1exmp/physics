# Задания к лабораторной работе «Определение удельной теплоёмкости вещества»

(c воды = 4200 Дж/(кг·°C))

## Подготовительные вопросы

1. Запишите формулу количества теплоты при нагревании.
2. Как выразить удельную теплоёмкость из формулы Q = c·m·Δt?
3. Зачем нужен калориметр? Почему он должен быть с теплоизоляцией?

## Обработка результатов опыта

Тело (металлический цилиндр) нагрели в кипящей воде (t₂ = 100 °C), затем опустили в холодную воду массой m₁ при температуре t₁ и измерили температуру равновесия t.

Вычислите:
- Q полученное водой = c_воды·m₁·(t − t₁)
- Q отданное телом = c·m₂·(t₂ − t)
- c = Q полученное / [m₂·(t₂ − t)]
- Определите вещество по таблице удельных теплоёмкостей

## Контрольные вопросы

**Вопрос 1.** Почему цилиндр перед опытом нужно держать в кипящей воде достаточно долго?

**Вопрос 2.** Почему измеренная теплоёмкость может отличаться от табличной?

**Вопрос 3.** Как уменьшить погрешность?

---

## Ответы

**Ответ 1:** чтобы его температура точно стала равна 100 °C — иначе расчёт начальной температуры тела будет неверен.
**Ответ 2:** часть теплоты уходит на нагрев калориметра и воздуха, есть погрешности измерения массы и температуры.
**Ответ 3:** использовать калориметр, быстро переносить цилиндр, брать больше воды, повторить опыт несколько раз и усреднить.
