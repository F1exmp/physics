# Задачи по теме «Парообразование и конденсация. Испарение»

## Базовый уровень

**Задача 1.** Какое количество теплоты нужно для превращения в пар 200 г воды, взятой при температуре кипения? (L = 2,3·10⁶ Дж/кг)
Решение: Q = L·m = 2,3·10⁶ · 0,2 = 4,6·10⁵ Дж.
Ответ: 460 кДж.

**Задача 2.** Какое количество теплоты выделится при конденсации 2 кг водяного пара при 100 °C?
Решение: Q = L·m = 2,3·10⁶ · 2 = 4,6·10⁶ Дж.
Ответ: 4,6 МДж.

## Средний уровень

**Задача 3.** Сколько энергии выделит при конденсации 50 г спирта? (L(спирта) = 0,9·10⁶ Дж/кг)
Решение: Q = L·m = 0,9·10⁶ · 0,05 = 4,5·10⁴ Дж.
Ответ: 45 кДж.

**Задача 4.** Сколько теплоты нужно затратить, чтобы испарить 3 кг эфира при температуре кипения? (L(эфира) = 0,4·10⁶ Дж/кг)
Решение: Q = L·m = 0,4·10⁶ · 3 = 1,2·10⁶ Дж.
Ответ: 1,2 МДж.

## Повышенный уровень

**Задача 5.** Сколько воды при 100 °C можно превратить в пар, затратив 2,07 МДж теплоты?
Решение: m = Q/L = 2,07·10⁶ / 2,3·10⁶ = 0,9 кг.
Ответ: 0,9 кг.

**Задача 6.** Вода массой 1 кг при температуре 20 °C доведена до кипения и полностью испарена. Какое количество теплоты для этого потребовалось? (c = 4200 Дж/(кг·°C), L = 2,3·10⁶ Дж/кг)
Решение:
1) Нагревание: Q₁ = c·m·Δt = 4200 · 1 · (100 − 20) = 3,36·10⁵ Дж.
2) Испарение: Q₂ = L·m = 2,3·10⁶ Дж.
3) Всего: Q = Q₁ + Q₂ = 3,36·10⁵ + 2,3·10⁶ = 2,636·10⁶ Дж.
Ответ: ≈ 2,64 МДж.
