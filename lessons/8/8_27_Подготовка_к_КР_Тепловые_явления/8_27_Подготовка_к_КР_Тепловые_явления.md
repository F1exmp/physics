# Урок 27. Подготовка к контрольной работе по теме «Тепловые явления. Изменение агрегатных состояний вещества»

**Класс:** 8
**Время:** 45 минут
**Цель урока:** Повторить и систематизировать материал раздела, отработать типовые задачи контрольной.

---

## 1. Организационный момент (2-3 мин)

Структура контрольной: 1 теоретическая часть (тест), 3–4 расчётные задачи, 1 качественная задача.

---

## 2. Повторение теории (10-12 мин)

**Основные понятия (быстрый опрос):**
- Внутренняя энергия и способы её изменения
- Три вида теплопередачи
- Количество теплоты, удельная теплоёмкость
- Уравнение теплового баланса
- Тепловое расширение
- Влажность воздуха, относительная влажность
- Плавление/отвердевание, λ; парообразование/конденсация, L
- Кипение и зависимость от давления
- Тепловые двигатели, КПД
- Закон сохранения энергии

**Сводка формул:**
- Q = c·m·Δt (нагревание/охлаждение)
- Q = λ·m (плавление/отвердевание)
- Q = L·m (парообразование/конденсация)
- Q = q·m (сгорание топлива)
- Q отд = Q пол (тепловой баланс)
- η = A/Q₁ · 100% (КПД двигателя)
- φ = ρ/ρ нас · 100% (влажность)

---

## 3. Разбор типовых задач (18-20 мин)

**Задача 1 (нагрев+плавление).** Сколько энергии нужно, чтобы 2 кг льда при −10 °C превратить в воду при 0 °C?
Решение: Q₁ = c_лёд·m·10 = 2100·2·10 = 42 кДж; Q₂ = λ·m = 340 000·2 = 680 кДж; всего 722 кДж.

**Задача 2 (тепловой баланс).** Смешали 3 кг воды при 90 °C и 2 кг при 20 °C: найти t.
Решение: 3·(90−t) = 2·(t−20) → 270−3t = 2t−40 → t = 62 °C.

**Задача 3 (испарение).** Сколько энергии надо, чтобы 1,5 кг воды при 100 °C испарить?
Решение: Q = L·m = 2,3·10⁶·1,5 = 3,45 МДж.

**Задача 4 (КПД).** Двигатель с КПД 25% совершил работу 5 МДж. Сколько топлива (q = 4,6·10⁷ Дж/кг) израсходовано?
Решение: Q₁ = A/η = 5·10⁶/0,25 = 20 МДж; m = Q₁/q = 2·10⁷/4,6·10⁷ ≈ 0,43 кг.

**Качественная задача:** почему зимой стакан с горячим чаем остывает быстрее, если на улице −30 °C, чем при −5 °C? (Больше разность температур — быстрее теплопередача.)
