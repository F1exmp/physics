ИНТЕРЕСНЫЕ ФАКТЫ:
─────────────────────────────────────────────────────────────────────────────
• Вода имеет одну из самых высоких λ среди жидкостей!
  λводы = 340 000 Дж/кг, тогда как λсвинец = 25 000 Дж/кг

• Благодаря высокой λ вода медленно нагревается и охлаждается.
  Это важно для климата Земли!

• λ используется в подводных лодках для охлаждения реакторов.
  (история: пуск первой советской АПЛ 1958 год)

ПРОБЛЕМА 1: Ученики не понимают теорию
─────────────────────────────────────────────────────────────────────────────
РЕШЕНИЕ:
• Провести более подробный опрос и объяснение
• Использовать аналогию (например, "ломка каркаса дома")
• Дополнительные примеры из жизни

ПРОБЛЕМА 2: Конечная температура ниже 0°C или ровно 0°C
─────────────────────────────────────────────────────────────────────────────
ПРИЧИНА:
• Слишком много льда или мало воды
• Лёд был слишком холодным
• Потеря тепла огромная

РЕШЕНИЕ:
• Повторить опыт с новыми данными
• Уменьшить количество льда
• Увеличить начальную температуру воды

ПРОБЛЕМА 3: Результат значительно отличается от табличного (>100%)
─────────────────────────────────────────────────────────────────────────────
ПРИЧИНА:
• Потеря тепла в окружающую среду (главная причина)
• Конденсат на льду увеличивал массу
• Лёд был значительно холоднее 0°C
• Систематические ошибки измерений

РЕШЕНИЕ:
• Объяснить, что это нормально для данной школы
• Провести обсчёд погрешностей
• Предложить идеи по улучшению эксперимента

ПРОБЛЕМА 4: Ученики путаются в переводе единиц (г → кг)
─────────────────────────────────────────────────────────────────────────────
РЕШЕНИЕ:
• Показать на доске: 100 г = 0,1 кг (делить на 1000)
• Дать формулу: m(кг) = m(г) / 1000
• Дать возможность использовать калькулятор
• Проверить первые переводы вместе

ПРОБЛЕМА 5: Не хватает времени для завершения работы
─────────────────────────────────────────────────────────────────────────────
РЕШЕНИЕ:
• Сократить количество опытов с 3 до 2
• Продолжить на третьем уроке (если возможно)
• Дать возможность закончить дома
• Оценить по тем результатам, которые есть
