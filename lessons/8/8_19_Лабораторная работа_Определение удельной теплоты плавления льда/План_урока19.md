ФИЗИЧЕСКИЙ СМЫСЛ ЭКСПЕРИМЕНТА:
----------------------------------------
🎯 Главная цель: экспериментально определить удельную теплоту плавления
        льда методом калориметрии.

💡 Суть метода: горячая вода отдаёт тепло лёду, лёд плавится и нагревает
        полученную воду. Зная количество теплоты, которое отдала вода,
        можно найти количество теплоты, которое получил лёд.

Отношение количества теплоты к массе льда даёт удельную теплоту плавления.

ПРИНЦИП КАЛОРИМЕТРИИ:
----------------------------------------
Метод калориметрии основан на законе сохранения энергии:

Qотдано = Qпринято

Где:
• Qотдано — количество теплоты, которое отдала вода при охлаждении
• Qпринято — количество теплоты, которое получил лёд (на плавление и нагревание)

Количество теплоты, которое отдала вода:
Qвода = c · mвода · (T1 - T2)

Количество теплоты, которое получил лёд:
Qлёд = Qпл + Qнагрев
     = λ · mлёд + c · mлёд · (T2 - 0°C)
     = mлёд · (λ + c · T2)

Из закона сохранения энергии:
Qвода = Qлёд

c · mвода · (T1 - T2) = mлёд · (λ + c · T2)

Отсюда выражаем λ:
λ = [c · mвода · (T1 - T2) / mлёд] - c · T2

ФОРМУЛЫ ДЛЯ РАСЧЁТОВ:
----------------------------------------
1. Количество теплоты, которое отдала вода:
   Qвода = c · mвода · (T1 - T2)

   где:
   c = 4200 Дж/(кг·°C) — удельная теплоёмкость воды
   mводa — масса воды (кг)
   T1 — начальная температура воды (°C)
   T2 — конечная температура смеси (°C)

2. Количество теплоты, которое ушло на нагревание воды, полученной при плавлении льда:
   Qнагрев = c · mлёд · T2

3. Количество теплоты, которое ушло на плавление льда:
   Qпл = Qвода - Qнагрев

4. Удельная теплота плавления льда:
   λ = Qпл / mлёд

   где:
   Qпл — количество теплоты на плавление (Дж)
   mлёд — масса льда (кг)

ОБРАБОТКА РЕЗУЛЬТАТОВ (пример расчёта):
----------------------------------------
Для опыт №1:
------------------------------------------------------------
ДАННЫЕ ДЛЯ РАСЧЁТА:
mводы = 0,1 кг (100 мл)
mлёд = 0,05 кг (50 г)
T1 = 60°C
T2 = 10°C
cводы = 4200 Дж/(кг·°C)

ШАГ 1: Рассчитываем количество теплоты, которое отдала вода:
Qвода = c · mводы · (T1 - T2)
Qводa = 4200 · 0,1 · (60 - 10)
Qводa = 4200 · 0,1 · 50
Qводa = 21000 Дж

ШАГ 2: Рассчитываем количество теплоты, которое ушло
      на нагревание воды, полученной при плавлении льда:
Qнагрев = c · mлёд · T2
Qнагрев = 4200 · 0,05 · 10
Qнагрев = 2100 Дж

ШАГ 3: Рассчитываем количество теплоты, которое ушло на плавление льда:
Qпл = Qвода - Qнагрев
Qпл = 21000 - 2100
Qпл = 18900 Дж

ШАГ 4: Рассчитываем удельную теплоту плавления льда:
λ = Qпл / mлёд
λ = 18900 / 0,05
λ = 378000 Дж/кг

ШАГ 5: Сравниваем с табличным значением:
λтабл = 340000 Дж/кг
Δλ = |λ - λтабл| = |378000 - 340000| = 38000 Дж/кг

Относительная погрешность:
ε = (Δλ / λтабл) · 100%
ε = (38000 / 340000) · 100% ≈ 11,2%

ВЫВОД: Полученное значение λ = 378000 Дж/кг отличается от табличного значения
        на 11,2%, что является допустимой погрешностью для лабораторной работы.

ПРОВЕРКА ПОНИМАНИЯ ТЕОРИИ (фронтальный опрос):
------------------------------------------------------------
1. Что такое удельная теплота плавления?
   - Физическая величина, показывающая, какое количество теплоты необходимо
     для плавления 1 кг вещества, уже нагретого до температуры плавления

2. Какой физический закон является основой метода калориметрии?
   - Закон сохранения энергии: Qотдано = Qпринято

3. Почему при плавлении температура не меняется?
   - Вся энергия идёт на разрушение кристаллической решётки

4. Чему равна температура плавления льда?
   - 0°C

5. Почему для плавления требуется энергия?
   - Для разрушения связей между частицами кристаллической решётки

6. Почему лёд должен иметь температуру 0°C?
   - Если лёд холоднее 0°C, дополнительно требуется энергия для его нагревания

7. Почему начальная температура воды должна быть 50-80°C?
   - Чтобы компенсировать потерю тепла в окружающую среду и получить
     точный результат

8. Как можно повысить точность эксперимента?
   - Уменьшить потерю тепла, провести несколько опытов, использовать
     более точные приборы

ВОПРОСЫ ДЛЯ АНАЛИЗА РЕЗУЛЬТАТОВ:
------------------------------------------------------------
9. Почему полученное значение λ отличается от табличного?

   Вероятные причины:
   • Потеря тепла в окружающую среду (калориметр неидеален)
   • Лёд имел температуру ниже 0°C
   • Конденсат на поверхности льда увеличивал его массу
   • Погрешность измерений (температуры, массы)
   • Неравномерное таяние льда

10. Как влияет масса льда на точность результата?
    • Слишком маленькая масса — большая относительная погрешность измерений
    • Слишком большая масса — вода может остыть ниже 0°C

11. Что будет, если конечная температура смеси окажется ниже 0°C?
    • Это невозможно физически: при 0°C происходит плавление, пока весь лёд
      не растает, и только потом температура может снизиться

12. Почему важно проводить несколько опытов?
    - Для повышения точности результата (среднее значение точнее)
    - Для выявления случайных ошибок

ЗАДАЧИ БАЗОВОГО УРОВНЯ (обязательные):

Задача 1:
Определите количество теплоты, необходимое для плавления 200 г льда.
Дано:
mлёд = 200 г = 0,2 кг
λ = 3,4 × 10⁵ Дж/кг

Найти: Q = ?

Решение:
Q = λ · m
Q = 3,4 × 10⁵ · 0,2 = 68000 Дж = 68 кДж

Ответ: Q = 68 кДж

---

Задача 2:
Какое количество теплоты выделится при кристаллизации 500 г воды?
Дано:
mводы = 500 г = 0,5 кг
λ = 3,4 × 10⁵ Дж/кг

Найти: Q = ?

Решение:
Q = λ · m (при кристаллизации выделяется столько же энергии, сколько
         поглощается при плавлении)
Q = 3,4 × 10⁵ · 0,5 = 170000 Дж = 170 кДж

Ответ: Q = 170 кДж

---

Задача 3:
В калориметре 150 г воды при температуре 70°C. Добавили 50 г льда при 0°C.
Какая установится температура после таяния льда?
Дано:
mводы = 150 г = 0,15 кг
Tводы = 70°C
mлёд = 50 г = 0,05 кг
с = 4200 Дж/(кг·°C)
λ = 3,4 × 10⁵ Дж/кг

Найти: Tконечная = ?

Решение:
1. Тепло, требуемое для плавления льда:
   Qпл = λ · mлёд = 3,4 × 10⁵ · 0,05 = 17000 Дж

2. Тепло, которое может отдать вода, если она охладится до 0°C:
   Qводы = c · mводы · (Tводы - 0) = 4200 · 0,15 · 70 = 44100 Дж

3. Так как Qводы > Qпл, лёд полностью растает и вода ещё останется тёплой:
   Тепло, оставшееся после плавления:
   Qост = Qводы - Qпл = 44100 - 17000 = 27100 Дж

4. Это тепло пойдёт на нагревание всей воды (mобщее = mводы + mлёд):
   Qост = c · mобщее · (Tводы - Tконечная)
   27100 = 4200 · 0,2 · (70 - Tконечная)
   27100 = 840 · (70 - Tконечная)
   70 - Tконечная = 27100 / 840 ≈ 32,3°C
   Tконечная = 70 - 32,3 ≈ 37,7°C

Ответ: Tконечная ≈ 38°C

Задача 6:
При определении удельной теплоты плавления льда ученик провёл три опыта:

Опыт 1: mводы = 0,15 кг, T1 = 60°C, T2 = 12°C, mлёд = 0,05 кг → λ₁ = ?
Опыт 2: mводы = 0,12 кг, T1 = 70°C, T2 = 15°C, mлёд = 0,04 кг → λ₂ = ?
Опыт 3: mводы = 0,18 кг, T1 = 55°C, T2 = 10°C, mлёд = 0,06 кг → λ₃ = ?

Решение ученика:
Вычислить λ для каждого опыта по формуле:
λ = [c · mводы · (T1 - T2) / mлёд] - c · T2

Опыт 1:
λ₁ = [4200 · 0,15 · (60 - 12) / 0,05] - 4200 · 12
λ₁ = [4200 · 0,15 · 48 / 0,05] - 50400
λ₁ = [30240 / 0,05] - 50400
λ₁ = 604800 - 50400 = 554400 Дж/кг

Опыт 2:
λ₂ = [4200 · 0,12 · (70 - 15) / 0,04] - 4200 · 15
λ₂ = [4200 · 0,12 · 55 / 0,04] - 63000
λ₂ = [27720 / 0,04] - 63000
λ₂ = 693000 - 63000 = 630000 Дж/кг

Опыт 3:
λ₃ = [4200 · 0,18 · (55 - 10) / 0,06] - 4200 · 10
λ₃ = [4200 · 0,18 · 45 / 0,06] - 42000
λ₃ = [34020 / 0,06] - 42000
λ₃ = 567000 - 42000 = 525000 Дж/кг

Среднее значение:
λср = (λ₁ + λ₂ + λ₃) / 3 = (554400 + 630000 + 525000) / 3
λср = 1709400 / 3 = 569800 Дж/кг

Относительная погрешность:
ε = (|λср - λтабл| / λтабл) · 100% = (|569800 - 340000| / 340000) · 100%
ε = (229800 / 340000) · 100% ≈ 67,6%

Задача 7:
В калориметр, содержащий m₁ = 200 г воды при температуре t₁ = 20°C, поместили
кусочки льда массой m₂ = 50 г при температуре t₂ = -10°C.
Найдите установившуюся температуру и процентное содержание льда (по массе)
в калориметре, если Useful теплоёмкость калориметра Cₖал = 167 Дж/К.

Дано:
m₁ = 200 г = 0,2 кг (воды)
t₁ = 20°C
m₂ = 50 г = 0,05 кг (льда)
t₂ = -10°C
с₁ = 4200 Дж/(кг·°C) (воды)
с₂ = 2100 Дж/(кг·°C) (льда)
λ = 3,4 × 10⁵ Дж/кг
Cₖал = 167 Дж/К

Найти: tконечная, ωлёд

Решение:
1. Тепло, которое можно получить от воды и калориметра, охладив их до 0°C:
   Q₁ = с₁ · m₁ · (t₁ - 0) = 4200 · 0,2 · 20 = 16800 Дж
   Q₂ = Cₖал · (t₁ - 0) = 167 · 20 = 3340 Дж
   Q₁₊₂ = Q₁ + Q₂ = 16800 + 3340 = 20140 Дж

2. Тепло, необходимое для нагревания льда от -10°C до 0°C:
   Q₃ = с₂ · m₂ · (0 - t₂) = 2100 · 0,05 · 10 = 1050 Дж

3. Тепло, необходимое для плавления всего льда:
   Q₄ = λ · m₂ = 340000 · 0,05 = 17000 Дж

4. Тепло, необходимое для полного нагревания и плавления льда:
   Q₃₊₄ = Q₃ + Q₄ = 1050 + 17000 = 18050 Дж

5. Сравнение:
   Q₁₊₂ = 20140 Дж > Q₃₊₄ = 18050 Дж
   Значит, весь лёд растает и температура смеси будет выше 0°C.

6. Оставшееся тепло пойдёт на нагревание воды:
   Qост = Q₁₊₂ - Q₃₊₄ = 20140 - 18050 = 2090 Дж

7. Масса всей воды после таяния:
   mобщее = m₁ + m₂ = 0,2 + 0,05 = 0,25 кг

8. Найдём конечную температуру:
   Qост = с₁ · mобщее · tконечная + Cₖал · tконечная
   Qост = tконечная · (с₁ · mобщее + Cₖал)
   2090 = tконечная · (4200 · 0,25 + 167/4200)
   2090 = tконечная · (1050 + 0,04)
   tконечная = 2090 / 1050,04 ≈ 2°C

Ответ: tконечная ≈ 2°C, весь лёд растаял (ωлёд = 0%)
