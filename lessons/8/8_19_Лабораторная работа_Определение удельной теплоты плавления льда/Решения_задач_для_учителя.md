Задача 1:
────────────────────────────────────────────────────────────────────────────
Сколько энергии нужно затратить, чтобы растопить 1,5 кг льда?

ДАНО:
mлёд = 1,5 кг
λ = 3,4 × 10⁵ Дж/кг

НАЙТИ:
Q = ?

РЕШЕНИЕ:
Q = λ · m
Q = 3,4 × 10⁵ · 1,5
Q = 5,1 × 10⁵ Дж = 510 000 Дж = 510 кДж

ОТВЕТ: Q = 510 кДж

Примечание для учителя:
Это базовая задача по формуле Q = λ · m. Ученики должны помнить
перевод единиц (1 кДж = 1000 Дж).


Задача 2:
────────────────────────────────────────────────────────────────────────────
Какое количество теплоты выделится при кристаллизации 0,8 кг воды?

ДАНО:
mводы = 0,8 кг
λ = 3,4 × 10⁵ Дж/кг

НАЙТИ:
Q = ?

РЕШЕНИЕ:
При кристаллизации выделяется такое же количество энергии, как
поглощается при плавлении (обратный процесс).

Q = λ · m
Q = 3,4 × 10⁵ · 0,8
Q = 2,72 × 10⁵ Дж = 272 000 Дж = 272 кДж

ОТВЕТ: Q = 272 кДж

Примечание для учителя:
Важно подчеркнуть, что кристаллизация и плавление — обратные процессы.
Энергия сохраняется, но меняется направление.


Задача 3:
────────────────────────────────────────────────────────────────────────────
В калориметр с водой массой 0,25 кг при 75°C добавили 0,08 кг льда.
Найдите установившуюся температуру.

ДАНО:
mводы = 0,25 кг
Tводы = 75°C
mлёд = 0,08 кг
с = 4200 Дж/(кг·°C)
λ = 3,4 × 10⁵ Дж/кг

НАЙТИ:
Tконечная = ?

РЕШЕНИЕ:
1. Тепло, требуемое для плавления льда:
   Qпл = λ · mлёд = 3,4 × 10⁵ · 0,08 = 27 200 Дж

2. Тепло, которое может отдать вода, если она охладится до 0°C:
   Qводы = с · mводы · (Tводы - 0) = 4200 · 0,25 · 75 = 78 750 Дж

3. Проверка, растает ли весь лёд:
   Qводы = 78 750 Дж > Qпл = 27 200 Дж
   Значит, весь лёд растает и температура смеси будет выше 0°C!

4. Тепло, которое остаётся после плавления:
   Qост = Qводы - Qпл = 78 750 - 27 200 = 51 550 Дж

5. Это тепло пойдёт на нагревание всей воды (mобщее = mводы + mлёд):
   Qост = с · mобщее · (Tводы - Tконечная)
   51 550 = 4200 · 0,33 · (75 - Tконечная)
   51 550 = 1386 · (75 - Tконечная)
   75 - Tконечная = 51 550 / 1386 ≈ 37,2°C
   Tконечная = 75 - 37,2 ≈ 37,8°C

ОТВЕТ: Tконечная ≈ 38°C

Примечание для учителя:
Это сложная задача, требующая understanding физического процесса.
Важно показать, что сначала нужно проверить, растает ли весь лёд.
Ученики могут запутаться в расчётах — проводить по шагам.

Задача 4:
────────────────────────────────────────────────────────────────────────────
В лабораторной работе ученик получил следующие данные:
mводы = 0,12 кг, T1 = 65°C, T2 = 15°C, mлёд = 0,04 кг
Определите удельную теплоту плавления льда по этим данным и объясните,
почему результат может отличаться от табличного.

ДАНО:
mводы = 0,12 кг
T1 = 65°C
T2 = 15°C
mлёд = 0,04 кг
с = 4200 Дж/(кг·°C)

НАЙТИ:
λ = ?

РЕШЕНИЕ:
1. Тепло, отданное водой:
   Qводы = с · mводы · (T1 - T2)
   Qводы = 4200 · 0,12 · (65 - 15)
   Qводы = 4200 · 0,12 · 50 = 25 200 Дж

2. Тепло на нагрев воды от таяния льда:
   Qнагрев = с · mлёд · T2
   Qнагрев = 4200 · 0,04 · 15 = 2520 Дж

3. Тепло на плавление льда:
   Qпл = Qводы - Qнагрев
   Qпл = 25 200 - 2520 = 22 680 Дж

4. Удельная теплота плавления:
   λ = Qпл / mлёд
   λ = 22 680 / 0,04 = 567 000 Дж/кг

5. Сравнение с табличным значением:
   λтабл = 340 000 Дж/кг
   Относительная погрешность:
   ε = (|567 000 - 340 000| / 340 000) · 100% = 66,8%

ОТВЕТ: λ = 567 000 Дж/кг, что превышает табличное значение на 66,8%

Почему результат отличается:
• Потеря тепла в окружающую среду (главная причина)
• Лёд мог иметь температуру ниже 0°C
• Конденсат на поверхности льда увеличивал его массу
• Погрешности измерений

Примечание для учителя:
Хорошая задача для проверки понимания метода. Ученики должны
уметь объяснить причины расхождения результатов.


Задача 5:
────────────────────────────────────────────────────────────────────────────
Сколько кг льда при 0°C нужно добавить к 5 кг воды при 20°C,
чтобы все лёд растаял, а конечная температура стала 10°C?

ДАНО:
mводы = 5 кг
Tводы = 20°C
Tсмеси = 10°C
с = 4200 Дж/(кг·°C)
λ = 3,4 × 10⁵ Дж/кг

НАЙТИ:
mлёд = ?

РЕШЕНИЕ:
1. Тепло, которое отдаст вода при остывании от 20°C до 10°C:
   Qводы = с · mводы · (Tводы - Tсмеси)
   Qводы = 4200 · 5 · (20 - 10)
   Qводы = 4200 · 5 · 10 = 210 000 Дж

2. Лёд потратит тепло на:
   a) Плавление: Qпл = λ · mлёд = 340 000 · mлёд
   b) Нагрев полученной воды от 0°C до 10°C:
      Qнагрев = с · mлёд · Tсмеси = 4200 · mлёд · 10 = 42 000 · mлёд

   Общее тепло, требуемое для льда:
   Qлёд = Qпл + Qнагрев = 340 000 · mлёд + 42 000 · mлёд = 382 000 · mлёд

3. По закону сохранения энергии: Qводы = Qлёд
   210 000 = 382 000 · mлёд
   mлёд = 210 000 / 382 000 ≈ 0,55 кг = 550 г

4. Проверка: весь лёд растает?
   На плавление требуется: λ · mлёд = 340 000 · 0,55 = 187 000 Дж
   Вода может отдать (если остынет до 0°C):
   с · mводы · Tводы = 4200 · 5 · 20 = 420 000 Дж
   420 000 > 187 000 → весь лёд растает ✓

ОТВЕТ: mлёд ≈ 0,55 кг = 550 г

Примечание для учителя:
Задача на применение обратной логики — по конечной температуре
находим массу льда. Ученики должны понимать, что нужно учитывать
и плавление льда, и нагрев воды от него.


Задача 6:
────────────────────────────────────────────────────────────────────────────
При определении λ льда ученик провёл 4 опыта и получил такие результаты:
Опыт 1: λ₁ = 380 000 Дж/кг
Опыт 2: λ₂ = 420 000 Дж/кг
Опыт 3: λ₃ = 290 000 Дж/кг
Опыт 4: λ₄ = 410 000 Дж/кг

Найдите среднее значение и оцените точность процесса.

РЕШЕНИЕ:
1. Среднее арифметическое:
   λср = (λ₁ + λ₂ + λ₃ + λ₄) / 4
   λср = (380 000 + 420 000 + 290 000 + 410 000) / 4
   λср = 1 500 000 / 4 = 375 000 Дж/кг

2. Отклонение каждого результата от среднего:
   Δ₁ = |380 000 - 375 000| = 5 000 Дж/кг
   Δ₂ = |420 000 - 375 000| = 45 000 Дж/кг
   Δ₃ = |290 000 - 375 000| = 85 000 Дж/кг
   Δ₄ = |410 000 - 375 000| = 35 000 Дж/кг

3. Среднее квадратичное отклонение (для понимания разброса):
   σ² = (Δ₁² + Δ₂² + Δ₃² + Δ₄²) / 3
   σ² = (5 000² + 45 000² + 85 000² + 35 000²) / 3
   σ² = (25·10⁶ + 2025·10⁶ + 7225·10⁶ + 1225·10⁶) / 3
   σ² = 10 500·10⁶ / 3 = 3500·10⁶ (Дж²/кг²)
   σ = √(3500·10⁶) ≈ 59 160 Дж/кг

4. Относительная погрешность по сравнению с табличным значением:
   λтабл = 340 000 Дж/кг
   ε = (|375 000 - 340 000| / 340 000) · 100%
   ε = (35 000 / 340 000) · 100% ≈ 10,3%

АНАЛИЗ:
• Среднее значение 375 000 Дж/кг отличается от табличного на 10,3%,
  что является хорошим результатом для лабораторной работы

• Разброс результатов значительный (опыт 3 даёт 290 000, что
  значительно отличается от среднего)

• Опыт 3, вероятно, содержит грубую ошибку (неверные измерения,
  потёмный инструмент и т.д.)

• Лучше всего отбросить опыт 3 и пересчитать:
  λср(без 3) = (380 000 + 420 000 + 410 000) / 3 = 403 333 Дж/кг
  ε = (|403 333 - 340 000| / 340 000) · 100% ≈ 18,6%

  Результат ухудшается! Значит, опыт 3 был точным, но случайно
  заниженным из-за какой-то причины (например, измеренная масса льда
  была больше из-за конденсата)

ОТВЕТ: λср = 375 000 Дж/кг, ε ≈ 10,3%, разброс результатов значителен

Примечание для учителя:
Задача на статистическую обработку экспериментальных данных.
Ученики знакомятся с понятием среднего значения и разброса.
Можно упростить — объяснить, что некоторые опыты могут давать
неточные результаты по случайным причинам.

Задача 7:
────────────────────────────────────────────────────────────────────────────
В калориметр, содержащий m₁ = 300 г воды при температуре t₁ = 25°C,
поместили кусочки льда массой m₂ = 100 г при температуре t₂ = -15°C.
Найдите: а) установившуюся температуру; б) состав смеси (сколько воды,
сколько льда), если полезная теплоёмкость калориметра Cₖал = 210 Дж/К.

ДАНО:
m₁ = 300 г = 0,3 кг (воды)
t₁ = 25°C
m₂ = 100 г = 0,1 кг (льда)
t₂ = -15°C
с₁ = 4200 Дж/(кг·°C) (воды)
с₂ = 2100 Дж/(кг·°C) (льда)
λ = 3,4 × 10⁵ Дж/кг
Cₖал = 210 Дж/К

НАЙТИ:
tконечная, состав смеси (massa воды, масса льда)

РЕШЕНИЕ:
1. Тепло, которое может быть получено от воды и калориметра при охлаждении до 0°C:
   Q₁ = с₁ · m₁ · (t₁ - 0) = 4200 · 0,3 · 25 = 31 500 Дж
   Q₂ = Cₖал · (t₁ - 0) = 210 · 25 = 5250 Дж
   Q₁₊₂ = Q₁ + Q₂ = 31 500 + 5250 = 36 750 Дж

2. Тепло, необходимое для нагревания льда от -15°C до 0°C:
   Q₃ = с₂ · m₂ · (0 - t₂) = 2100 · 0,1 · 15 = 3150 Дж

3. Тепло, необходимое для плавления всего льда:
   Q₄ = λ · m₂ = 340 000 · 0,1 = 34 000 Дж

4. Тепло, необходимое для полного нагревания и плавления всего льда:
   Q₃₊₄ = Q₃ + Q₄ = 3150 + 34 000 = 37 150 Дж

5. Сравнение:
   Q₁₊₂ = 36 750 Дж < Q₃₊₄ = 37 150 Дж
   Разница: ΔQ = Q₃₊₄ - Q₁₊₂ = 400 Дж

   Вывод:
   • Вода и калориметр охладятся до 0°C
   • Лёд нагреется от -15°C до 0°C
   • Часть льда расплавится, но не весь!

6. Найдём, сколько льда расплавится:
   На нагревание льда ушло: Q₃ = 3150 Дж
   На плавление осталось: Qпл = Q₁₊₂ - Q₃ = 36 750 - 3150 = 33 600 Дж

   Масса расплавившегося льда:
   mрасп = Qпл / λ = 33 600 / 340 000 ≈ 0,0988 кг ≈ 98,8 г

7. Конечная смесь:
   • Вода: 300 г (изначальная) + 98,8 г (от таяния льда) = 398,8 г
   • Лёд: 100 г (изначальный) - 98,8 г (расплавилось) = 1,2 г
   • Температура: 0°C

А) tконечная = 0°C
Б) Смесь состоит из ≈ 399 г воды и ≈ 1 г льда при температуре 0°C

ОТВЕТ: tконечная = 0°C; смесь содержит ≈ 399 г воды и ≈ 1 г льда

Примечание для учителя:
Сложная задача на случай, когда не весь лёд растает.
Ученики должны понять критерий:
- Если Qводы+Qкал > Qнагрев_льда + Qплавление_всего_льда → льду хватит тепла
  для полного плавления
- Если Qводы+Qкал < Qнагрев_льда + Qплавление_всего_льда → часть льда останется

Рекомендуется для сильных учеников в качестве дополнительного задания.
