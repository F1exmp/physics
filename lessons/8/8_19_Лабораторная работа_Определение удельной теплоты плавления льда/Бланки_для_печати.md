ШАГ 4: ЗАПОЛНИТЕ ТАБЛИЦУ
─────────────────────────────────────────────────•
• Заполните все ячейки (не оставляйте пустыми)
• Правильно переведите единицы (г → кг)
• Проверьте, что T2 > 0°C


ШАГ 5: ПОСЧИТАЙТЕ ПО ФОРМУЛАМ
─────────────────────────────────────────────────•
Для каждого опыта:

1. Qводы = 4200 · mводы · (T1 - T2)
   
   Пример: mводы = 0,1 кг, T1 = 70°C, T2 = 15°C
   Qводы = 4200 · 0,1 · (70 - 15) = 4200 · 0,1 · 55 = 23 100 Дж

2. Qнагрев = 4200 · mлёд · T2
   
   Пример: mлёд = 0,04 кг, T2 = 15°C
   Qнагрев = 4200 · 0,04 · 15 = 2 520 Дж

3. Qпл = Qводы - Qнагрев
   
   Пример: Qпл = 23 100 - 2 520 = 20 580 Дж

4. λ = Qпл / mлёд
   
   Пример: λ = 20 580 / 0,04 = 514 500 Дж/кг


ШАГ 6: НАЙДИТЕ СРЕДНЕЕ ЗНАЧЕНИЕ
─────────────────────────────────────────────────•
λср = (λ₁ + λ₂ + λ₃) / 3

Пример: λ₁ = 520 000, λ₂ = 480 000, λ₃ = 500 000
λср = (520 000 + 480 000 + 500 000) / 3 = 1 500 000 / 3 = 500 000


ШАГ 7: ОЦЕНИТЕ ПОГРЕШНОСТЬ
─────────────────────────────────────────────────•
Δλ = |λср - λтабл|

Пример: Δλ = |500 000 - 340 000| = 160 000 Дж/кг

ε = (Δλ / λтабл) · 100%

Пример: ε = (160 000 / 340 000) · 100% ≈ 47%
