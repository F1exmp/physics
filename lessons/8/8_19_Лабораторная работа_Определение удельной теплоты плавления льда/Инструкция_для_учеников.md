# "Определение удельной теплоты плавления льда"

================================================================================
ЦЕЛЬ РАБОТЫ
================================================================================

Экспериментально определить удельную теплоту плавления льда методом
калориметрии.

Что такое удельная теплота плавления?
Это физическая величина λ, показывающая, какое количество теплоты необходимо
для плавления 1 кг вещества при температуре плавления.

Для льда λ = 340 000 Дж/кг (табличное значение)


================================================================================
СУТЬ МЕТОДА КАЛОРИМЕТРИИ
================================================================================

Метод основан на законе сохранения энергии:
 количеству теплоты, которое отдаёт вода при охлаждении


ФОРМУЛЫ:
────────────────────────────────────────────────────────────────────────────

1. Тепло, отданное водой:
   Qводы = c · mводы · (T1 - T2)

   где:
   c = 4200 Дж/(кг·°C) — удельная теплоёмкость воды
   mводы — масса воды (кг)
   T1 — начальная температура воды (°C)
   T2 — конечная температура смеси (°C)

2. Тепло на нагревание воды от таяния льда:
   Qнагрев = c · mлёд · T2

3. Тепло на плавление льда:
   Qпл = Qводы - Qнагрев

4. Удельная теплота плавления:
   λ = Qпл / mлёд

================================================================================

ШАГ 1. Подготовка (5 минут)
────────────────────────────────────────────────────────────────────────────
1. Подготовьте бланк для записи результатов
2. Проверьте исправность оборудования
3. Распределите роли (если работаете в паре):
   - Измеритель — проводит измерения
   - Записывающий — записывает данные


ШАГ 2. Подготовка калориметра с водой (10 минут)
────────────────────────────────────────────────────────────────────────────
1. Возьмите мензурку и отмерьте 100-150 мл воды
2. Измерьте температуру воды (должна быть 50-80°C)
3. Перелейте воду во внутренний стакан калориметра
4. Поместите внутренний стакан во внешний (для тепловой изоляции)
5. Запишите:
   • mводы = ________ мл → переведите в кг: ________ кг
   • T1 = ________ °C

Важно: Правила перевода единиц!
1 мл воды ≈ 1 г воды
100 мл = 100 г = 0,1 кг


ШАГ 3. Подготовка льда (3 минуты)
────────────────────────────────────────────────────────────────────────────
1. Возьмите дроблённый лёд (50-80 г)
2. Убедитесь, что лёд имеет температуру около 0°C
   (предварительно выдержали при комнатной температуре)
3. Измерьте массу льда на весах
4. Запишите:
   • mлёд = ________ г = ________ кг

Важно: Масса льда должна быть примерно в 2-3 раза меньше массы воды!


ШАГ 4. Проведение эксперимента (15 минут)
────────────────────────────────────────────────────────────────────────────
1. Вставьте термометр в воду в калориметре
2. Следите за показаниями термометра (убедитесь, что T1 стабильна)
3. Быстро поместите лёд в калориметр с водой
4. Оставьте лёд в воде, пока он полностью не растаят
   (можно осторожно помешивать стеклянной палочкой)

⏱️ В это время наблюдайте:
   - Как меняется температура?
   - Сколько времени тает лёд?


ШАГ 5. Измерение конечной температуры (3 минуты)
────────────────────────────────────────────────────────────────────────────
1. После полного таяния льда измерьте температуру смеси
2. Убедитесь, что температура стабильна
3. Запишите:
   • T2 = ________ °C

Важно: T2 должна быть выше 0°C (примерно 5-15°C)!


ШАГ 6. Повторение опыта (20 минут)
────────────────────────────────────────────────────────────────────────────
1. Повторите эксперимент ещё 2 раза (всего 3 опыта)
2. Для каждого опыта используйте новую порцию воды и льда
3. Заполните таблицу результатов

ПРИМЕР РАСЧЁТА (для одного опыта)
================================================================================

Исходные данные:
────────────────────────────────────────────────────────────────────────────
mводы = 0,12 кг (120 мл)
T1 = 70°C
T2 = 15°C
mлёд = 0,04 кг (40 г)
c = 4200 Дж/(кг·°C)


Расчёты:
────────────────────────────────────────────────────────────────────────────

1. Тепло, отданное водой:
   Qводы = c · mводы · (T1 - T2)
   Qводы = 4200 · 0,12 · (70 - 15)
   Qводы = 4200 · 0,12 · 55
   Qводы = 27720 Дж

2. Тепло на нагрев воды от таяния льда:
   Qнагрев = c · mлёд · T2
   Qнагрев = 4200 · 0,04 · 15
   Qнагрев = 2520 Дж

3. Тепло на плавление льда:
   Qпл = Qводы - Qнагрев
   Qпл = 27720 - 2520
   Qпл = 25200 Дж

4. Удельная теплота плавления:
   λ = Qпл / mлёд
   λ = 25200 / 0,04
   λ = 630000 Дж/кг

   Сравнение с табличным значением:
   λтабл = 340000 Дж/кг
   Различие: значительное (почти в 2 раза!)
   Причина: потеря тепла в окружающую среду, погрешности измерений
