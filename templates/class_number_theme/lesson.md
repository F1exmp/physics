1. Организационный момент (2-3 мин) — приветствие, цель урока
2. Актуализация знаний (5-7 мин) — связь с предыдущими темами
3. Историческая справка:
    * Краткая биография учёного (имя + вклад + интересный факт)
    * Исторические условия открытия
    * Эксперимент/наблюдение
    * Связка с темой урока
4. Объяснение нового материала (15-20 мин) — мотивация, изложение, первичное закрепление
5. Закрепление (10-12 мин) — решение задач, работа в парах
6. Домашнее задание и рефлексия (3-5 мин) — итог урока, запись домашнего задания
